# 06 队伍与角色切换

## 1. 设计目标

四人队伍是原神玩法的基本单位。复刻要点：**切人是零成本的**（除了短 CD 与后摇），**场外角色是活着的**（持续效果继续结算），**队伍构成本身提供数值**（元素共鸣）。

## 2. 编队规则

- 队伍容量 4 人，可少于 4 人。
- 同一角色不可重复上阵（旅行者的不同元素形态视为同一角色）。
- 队伍配置在世界中可随时修改，战斗中不可修改。
- 支持多套队伍预设（至少 4 套），可一键切换。

## 3. 角色切换

### 3.1 切换规则

| 项 | 规则 |
| --- | --- |
| 输入 | 数字键 1-4 / 手柄方向键 |
| CD | 1 秒【待复核】，全队共享一条 |
| 允许条件 | 非元素爆发释放中、非过场演出中、非受击硬直中 |
| 位置 | 新角色出现在旧角色位置，继承朝向 |
| 动画 | 播放切入动画，期间可被普攻/E/Q 取消 |

### 3.2 切换时的状态继承

| 状态 | 是否继承 |
| --- | --- |
| 位置与朝向 | 继承 |
| 体力 | 全队共享，继承 |
| 空中状态（跳跃/滑翔） | 继承 |
| 连段计数 | **不继承**，新角色从 N1 开始 |
| 元素附着（角色自身被附着） | 不继承，各角色独立 |
| Buff | 按 Buff 定义，队伍 Buff 继承，角色 Buff 不继承 |

### 3.3 切换的特殊窗口

切入瞬间存在一段**切换无敌帧**（约 0.2 秒）【待复核】，防止切人瞬间被秒。

## 4. 场外角色

### 4.1 场外角色仍然存在的东西

- E/Q 产生的持续效果、召唤物、场域（见 `03` 第 5 节）；
- 生命值状态：场外角色可被范围伤害波及并死亡【待复核，原神中场外角色不受伤害】；
- 能量：持续接收微粒。

> **明确结论**：原神中场外角色**不承受任何伤害**。现有代码 `AttackedLogic` 中「后台成员继续结算伤害与 Effect」的处理需要调整，见 `90`。

### 4.2 队伍全灭

队伍中全部角色生命值归零时进入失败流程：世界中复活于最近的七天神像，秘境中挑战失败。

## 5. 元素共鸣

队伍中存在 2 名及以上同元素角色时触发对应共鸣；4 人队最多触发 2 种共鸣。队伍不足 4 人时不触发任何共鸣。

| 共鸣 | 条件 | 效果 |
| --- | --- | --- |
| 热诚之火 | 2 火 | 攻击力 +25%；受冰影响时间 −40% |
| 愈疗之水 | 2 水 | 受治疗加成 +30%；受火影响时间 −40% |
| 迅捷之风 | 2 风 | 体力消耗 −15%；移动速度 +10%；技能 CD −5% |
| 坚定之岩 | 2 岩 | 护盾强效 +15%；护盾状态下伤害 +15%、削弱敌人 20% 对应抗性 |
| 蔓生之草 | 2 草 | 元素精通 +50；触发相关反应后进一步提升全队精通 |
| 粉碎之冰 | 2 冰 | 对冰附着/冻结目标暴击率 +15%；受雷影响时间 −40% |
| 交叠之雷 | 2 雷 | 触发相关反应时产生 1 个雷元素微粒（CD 5 秒）；受水影响时间 −40% |
| 破局之刃 | 4 种不同元素 | 暴击率 +10%；冷却缩减 −5%（即 CD 缩短 5%） |

【待复核】具体数值需以当前版本确认。

## 6. 运行时结构

`TeamSystem` 扩展现有实现：

```csharp
public interface ITeamSystem : ISystemContract
{
    // 当前上场成员，切换时发布 ActiveMemberChangedEvent。
    ITeamMember ActiveMember { get; }

    // 全部队伍成员（含场外），供持续效果与能量分发遍历。
    IReadOnlyList<ITeamMember> Members { get; }

    // 当前生效的元素共鸣集合，队伍变更时重算。
    IReadOnlyList<ElementalResonance> Resonances { get; }

    // 请求切换到指定槽位；受 CD 与控制状态约束，返回是否受理。
    bool RequestSwitch(int slotIndex);
}
```

元素共鸣以永久 `EffectDefinition` 的形式施加到全队，复用 `RuntimePermanentEffectProjection` 的既有模式，队伍变更时重建投影。

## 7. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| T-01 | 战斗中按 2 切人 | 新角色在原位出现，1 秒内无法再切 |
| T-02 | 元素爆发释放中按切人 | 输入被拒绝 |
| T-03 | 空中切人 | 保持空中状态，可继续滑翔 |
| T-04 | 切人后角色被范围伤害命中 | 只有上场角色掉血 |
| T-05 | 2 火角色组队 | 全队攻击力 +25% |
| T-06 | 4 种元素组队 | 触发破局之刃 |
| T-07 | 3 人队伍 | 不触发任何共鸣 |
| T-08 | 队伍编成中途更换角色 | 共鸣重算，旧共鸣效果移除 |
| T-09 | 全队生命值归零 | 进入复活流程 |
