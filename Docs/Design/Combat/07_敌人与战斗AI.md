# 07 敌人与战斗AI

## 1. 设计目标

原神的敌人设计服务于一个目的：**给元素系统提供表达空间**。元素护盾强制玩家组特定队伍，元素亲和让部分反应失效，Boss 相位切换制造输出窗口。敌人本身的 AI 复杂度是次要的，元素交互规则才是主体。

## 2. 敌人分类

| 类别 | 特征 | 举例 |
| --- | --- | --- |
| 普通怪 | 低血量、无护盾、快速刷新 | 丘丘人、史莱姆 |
| 元素怪 | 携带元素附着或元素护盾 | 元素史莱姆、丘丘萨满 |
| 精英怪 | 高血量、有护盾或特殊机制、限时刷新 | 遗迹守卫、深渊法师 |
| 世界 Boss | 多相位、消耗树脂掉落 | 各类领主 |
| 周本 Boss | 多相位、高强度、周限次数 | 各类魔神/首领 |

## 3. 敌人属性

| 属性 | 说明 |
| --- | --- |
| 等级 | 参与防御区计算（见 `05`） |
| 生命值 | 按等级与类别曲线成长 |
| 防御力 | 由等级推导 |
| 八系抗性 | 基础值通常为 10%，部分敌人对自身元素为 高抗或免疫 |
| 硬直等级 | 抗打断能力，见 `08` |
| 元素亲和 | 自身元素，决定其对应抗性与可否被自身元素附着 |

**元素免疫规则**：敌人对自身元素通常抗性极高甚至免疫（如火深渊法师对火伤害）。这类敌人**无法被自身元素附着**，因此无法用该元素触发反应。

## 4. 元素护盾

元素护盾是原神敌人设计的核心机制，必须完整复刻。

### 4.1 护盾规则

- 护盾拥有独立于生命值的耐久值；
- 护盾存在期间，敌人处于霸体，无法被打断；
- 护盾被击破后敌人进入**破盾硬直**，持续数秒，期间受到的伤害提高；
- 护盾会随时间自动恢复（部分敌人）。

### 4.2 元素克制效率

对护盾造成的耐久削减按下表乘算：

| 伤害类型 | 削减效率 |
| --- | --- |
| 物理伤害 | 0.5× |
| 与护盾相同元素 | 0.5× |
| 无关元素 | 1.0× |
| **克制元素**（见 4.3） | 2.0× |
| 剧变反应（超载/超导/碎冰/扩散等） | 2.0× |
| 结晶反应 | 1.0× |

【待复核】具体倍率需实机测定。

### 4.3 护盾克制表

| 护盾类型 | 克制元素 |
| --- | --- |
| 火盾 | 水 |
| 水盾 | 冰、雷 |
| 雷盾 | 冰 |
| 冰盾 | 火 |
| 草盾 | 火 |
| 风盾 | 全元素（等效） |
| 岩盾 | 双手剑、岩元素、下落攻击等「钝击」类 |

### 4.4 配置结构

```csharp
// 描述一层元素护盾的耐久、克制规则与破盾后行为。
public struct ElementalShieldDefinition
{
    public ElementType ShieldElement;
    public float Durability;            // 耐久值，独立于生命值
    public float RegenDelay;            // 破盾后重新生成延迟，负值表示不再生成
    public float BreakStaggerDuration;  // 破盾硬直时长
    public float BreakDamageTakenBonus; // 破盾期间受伤加成
    public bool GrantsSuperArmor;       // 护盾存在期间是否霸体
}
```

## 5. AI 结构

现有 `EnemyAiBrain` / `EnemyAiDefinition` / `EnemyAiLogic` / `EnmityComponent` / `PatrolComponent` 已提供骨架，复刻时按下列结构扩展。

### 5.1 AI 状态机

```text
Idle ──(感知到目标)──→ Alert ──→ Combat
 ↑                                 │
 │                                 ├─→ Approach（接近）
 Patrol ←──(脱战超时)──────────────┤
                                   ├─→ Attack（执行攻击）
                                   ├─→ Reposition（走位）
                                   └─→ Flee / Special（特殊行为）
```

### 5.2 感知

| 参数 | 说明 |
| --- | --- |
| 视野半径 | 敌人主动发现目标的距离 |
| 视野角度 | 前方扇形角度 |
| 听觉半径 | 不受角度限制的感知范围 |
| 受击强制仇恨 | 被攻击时立即进入战斗，无视感知 |

### 5.3 仇恨

- 仇恨目标为**上场角色**。上场角色切换时，敌人仇恨立即转移到新角色。
- 现有 `EnmityConfig` / `EnmityComponent` 承载该逻辑，需确保切人时正确转移。
- 部分召唤物具备嘲讽能力，可临时夺取仇恨。

### 5.4 攻击选择

每个敌人配置一组攻击动作，每个动作带：

```csharp
// 描述敌人一个可选攻击及其选择条件与冷却。
public struct EnemyAttackOption
{
    public int AttackId;
    public float MinRange, MaxRange;   // 适用距离区间
    public float Cooldown;             // 单动作冷却
    public float Weight;               // 同时可用时的随机权重
    public float MinHpRatio, MaxHpRatio; // 生命值区间门槛，用于相位专属招式
    public bool RequiresLineOfSight;
}
```

选择流程：过滤可用动作（距离、CD、生命值门槛、视线）→ 按权重随机 → 执行。执行期间进入攻击动作状态，不可重新选择。

### 5.5 相位（Boss）

```csharp
// 描述 Boss 的一个战斗相位及其进入条件与切换表现。
public struct BossPhase
{
    public int PhaseId;
    public float EnterHpRatio;          // 生命值降至该比例进入本相位
    public float TransitionDuration;    // 相位切换演出时长，期间通常无敌
    public int[] UnlockedAttackIds;     // 本相位解锁的攻击
    public ElementalShieldDefinition[] Shields; // 本相位的护盾配置
    public bool IsInvulnerableDuringTransition;
}
```

相位切换是玩家的主要输出窗口设计位，必须支持「切换演出期间无敌」与「切换后进入虚弱」两种模式。

## 6. 敌人的元素交互

- 敌人身上的附着与反应规则与角色**完全一致**，共用 `04` 的 `ElementSystem`；
- 敌人对玩家造成的伤害同样可以附着元素，玩家被附着后同样可触发反应（如被感电）；
- 元素亲和为某元素的敌人无法被该元素附着，因此无法用该元素启动反应链。

## 7. 刷新与掉落

| 项 | 规则 |
| --- | --- |
| 普通怪 | 击杀后在玩家离开区域并经过一定时间后刷新 |
| 精英怪 | 每日刷新，掉落需消耗树脂 |
| 世界 Boss | 击杀后固定时间刷新，掉落需消耗树脂领取 |
| 掉落归属 | 掉落表按敌人类型与等级区间配置 |

掉落与树脂属于养成系统范畴，本案只定义触发点与接口，具体规则另案。

## 8. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| N-01 | 玩家进入敌人视野 | 进入战斗并接近 |
| N-02 | 远距离攻击未进入视野的敌人 | 敌人立即进战并仇恨攻击者 |
| N-03 | 战斗中切人 | 仇恨转移到新上场角色 |
| N-04 | 用水攻击火盾深渊法师 | 护盾耐久按 2 倍效率削减 |
| N-05 | 用火攻击火盾深渊法师 | 按 0.5 倍效率，且无法附着火 |
| N-06 | 护盾存在时攻击 | 敌人不产生硬直 |
| N-07 | 击破护盾 | 进入破盾硬直，受伤加成生效 |
| N-08 | Boss 生命值降至相位阈值 | 播放切换演出，期间无敌 |
| N-09 | 玩家脱离战斗区域一定时间 | 敌人回归巡逻并恢复生命值 |
| N-10 | 敌人攻击附着雷元素到玩家 | 玩家身上产生雷附着，可被水触发感电 |
