# 01 角色动作与移动

## 1. 设计目标

原神的移动系统之所以特殊，在于它**没有边界**：攀爬、游泳、滑翔不是分离的玩法模式，而是同一个角色控制器的连续状态。任意一面墙都能爬，任意高度都能跳下滑翔，任意水面都能游。体力是唯一把这些能力统一约束起来的资源。

## 2. 移动状态机

```text
                    ┌──────────────────────────────────┐
                    ↓                                  │
Idle ⇄ Walk ⇄ Run ⇄ Sprint                             │
  │                                                    │
  ├─(跳跃)→ Jump ─→ Fall ─┬─(接近地面)→ Land ──────────┘
  │                       ├─(按跳跃)→ Glide ─┬─(落地)→ Land
  │                       │                  └─(入水)→ Swim
  │                       └─(贴墙且可攀)→ Climb
  │
  ├─(贴墙前进)→ Climb ⇄ ClimbSprint ─(到顶)→ ClimbOver
  │
  └─(进入水域)→ Swim ⇄ SwimFast ─(离岸)→ Idle
```

现有 `GroundMoveLogic` / `AirMoveLogic` / `JumpLogic` / `LandLogic` / `GravityLogic` / `MotionLogic` 已覆盖地面与空中；**攀爬、游泳、滑翔三套状态需新增**。

## 3. 地面移动

### 3.1 速度档位

由 `PropertyConfig` 已有的 `walkSpeed` / `runSpeed` / `sprintSpeed` 承载，输入强度决定档位：

| 档位 | 触发 | 速度参考 |
| --- | --- | --- |
| 走 | 摇杆偏移 < `walkEdge`(0.2) | 约 1.5 m/s |
| 跑 | 摇杆偏移 ≥ `walkEdge` | 约 4 m/s |
| 冲刺 | 按冲刺键 | 约 6 m/s |

现有的 `walkEdge` / `sprintEdge` / `damp` 字段语义与此一致，可直接复用。

### 3.2 转向

- 移动转向使用阻尼插值（`damp`）；
- 攻击起手瞬间强制朝向软锁定目标，见 `02` 第 6.3 节。

### 3.3 地形

- 坡度 ≤ 约 50° 可正常行走，超过则滑落或转为攀爬；
- 不同地表材质影响脚步音效与足迹 VFX（见 `09`）；
- 水面在被冰元素附着后成为可行走地面，这条规则由 `04` 的元素系统驱动，不是移动系统的特例。

## 4. 跳跃与下落

- 跳跃为单段，无二段跳；
- 跳跃初速由 `jumpSpeed` 决定，重力由 `gravity` 决定；
- 空中可水平移动，速度为 `airMoveSpeed`；
- 下落高度超过阈值（约 8 米）产生坠落伤害，伤害随高度递增，超过约 20 米致死【待复核】；
- 空中按攻击键进入下落攻击，见 `02`。

## 5. 攀爬

| 项 | 规则 |
| --- | --- |
| 触发 | 面向可攀爬表面并持续前进输入 |
| 可攀爬判定 | 表面法线与水平夹角 < 约 40°，且未标记为 `NoClimb` |
| 移动 | 上下左右四向，速度约 1.5 m/s |
| 体力 | 约 5/秒；冲刺攀爬约 25/秒 |
| 跳跃 | 攀爬中可向上蹬跳，消耗固定体力（约 20） |
| 翻越 | 到达顶部边缘自动播放翻越动画 |
| 中断 | 体力耗尽自动下坠；按跳跃键可主动脱离并转入下落 |

攀爬期间**禁止任何战斗动作**，受击立即脱落。

## 6. 游泳

| 项 | 规则 |
| --- | --- |
| 触发 | 进入水域且水深超过阈值 |
| 速度 | 常规约 2 m/s；快速游泳约 3 m/s |
| 体力 | 常规约 4/秒；快速约 12/秒 |
| 战斗 | 水中禁止一切战斗动作与元素释放 |
| 溺水 | 体力归零后传送至最近岸边并扣除生命值 |
| 结冰 | 水面被冰附着后转为可行走地面 |

## 7. 滑翔

| 项 | 规则 |
| --- | --- |
| 触发 | 下落状态中按跳跃键 |
| 水平速度 | 约 6 m/s，可被风场加速 |
| 下坠速度 | 约 2 m/s |
| 体力 | 约 3.3/秒【待复核】 |
| 中断 | 落地、入水、体力耗尽（转为自由下落）、主动取消 |
| 风场 | 上升气流提供垂直加速，不消耗额外体力 |

滑翔中禁止战斗动作，但允许切换角色。

## 8. 体力

体力的完整消耗表见 `02` 第 5 节。此处补充恢复规则：

- 停止消耗后延迟约 1 秒开始恢复；
- 恢复速率约 25/秒【待复核】；
- 处于滑翔、攀爬、游泳状态时**不恢复**，即使当前未主动消耗；
- 体力为**全队共享资源**，切人不重置。

## 9. 控制状态

移动能力受控制状态约束，复用现有 `ControlState` 机制：

| 状态 | 禁止 |
| --- | --- |
| Stun | 全部移动与战斗 |
| Root | 位移，允许转向与攻击 |
| Frozen | 全部行为，且受击后碎冰 |
| Attacked | 主动输入（硬直期间），见 `08` |
| InCutscene | 全部玩家输入 |

现有 `PropertyComponent.AddControlStateModifier` 的句柄式贡献模型可直接承载，无需改造。

## 10. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| M-01 | 摇杆轻推 | 进入走路，不消耗体力 |
| M-02 | 冲刺至体力耗尽 | 自动转为跑，1 秒后开始恢复 |
| M-03 | 面向陡坡前进 | 自动进入攀爬 |
| M-04 | 攀爬中体力耗尽 | 脱落转入下落 |
| M-05 | 高空下落中按跳跃 | 展开滑翔 |
| M-06 | 滑翔中切人 | 切换成功且保持滑翔 |
| M-07 | 滑翔中体力耗尽 | 收翼自由下落，产生坠落伤害 |
| M-08 | 水面被冰附着后踏上 | 可正常行走 |
| M-09 | 游泳中体力耗尽 | 传送回岸并扣血 |
| M-10 | 攀爬中受击 | 立即脱落 |
