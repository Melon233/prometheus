# 08 受击反馈与硬直

## 1. 设计目标

硬直系统决定了「攻击能不能打断对方」这件事的全部质感。原神采用**分级硬直**而非布尔打断：不同攻击有不同的打断能力，不同敌人有不同的抗打断等级，两者比较决定结果。现有实现是「打断能力 > 韧性即 Stun」的二值模型，需要升级为分级模型。

## 2. 硬直等级

### 2.1 攻击侧：打断等级

每段攻击配置一个打断等级：

| 等级 | 名称 | 典型来源 |
| --- | --- | --- |
| 0 | 无打断 | DOT、剧变反应伤害、部分场域 |
| 1 | 轻微 | 单手剑普攻、弓普攻、法器普攻 |
| 2 | 一般 | 长柄普攻、重击、多数元素战技 |
| 3 | 较强 | 双手剑普攻、下落攻击 |
| 4 | 强 | 多数元素爆发、双手剑重击终结 |
| 5 | 极强 | 特定强控技能、超载击退 |

### 2.2 受击侧：抗打断等级

每个单位配置一个抗打断等级（沿用现有 `PropertyConfig.toughness` 字段位，语义改为分级值）：

| 等级 | 表现 |
| --- | --- |
| 0 | 任何攻击都打断（小型敌人） |
| 1-2 | 一般敌人 |
| 3-4 | 精英怪 |
| 5+ | Boss、护盾状态、霸体状态 |

### 2.3 判定规则

```text
打断成立  ⟺  攻击打断等级 > 目标抗打断等级
```

- 打断成立 → 目标进入受击硬直，播放受击动画，当前动作被中断；
- 打断不成立 → 目标正常受伤，播放**轻微受击反馈**（材质闪白、受击特效），但动作不中断。

**霸体（Super Armor）**：临时将抗打断等级提升到极高值，由 `EffectDefinition` 施加。敌人施放大招前摇、元素护盾存在期间、Boss 相位切换期间均处于霸体。

## 2.4 实现状态

**分级模型与霸体已落地。**

| 项 | 状态 |
| --- | --- |
| `攻击打断等级 > 目标抗打断等级` 的分级判定 | 已完成，在 `DamageSettlement.PublishStaggerEvents` |
| 攻击侧打断等级 | 已完成，`DamageOperation.staggerLevel`（整数配置，不再是数值公式） |
| 受击侧抗打断等级 | 已完成，`PropertyConfig.staggerResistance` → `PropertyType.StaggerResistance` |
| 霸体覆盖 | 已完成，`PropertyType.SuperArmor` 非零时**覆盖**抗打断等级 |
| 打断不成立的轻微受击事实 | 已完成，`StaggerResistedEvent` |
| 轻微受击的**表现**（闪白、命中 VFX） | **未完成**，属排期第 9 步 |
| 每段攻击各自的打断等级 | **未完成**，需要天赋段落表提供该列，属排期第 5 步 |
| 受击霸体（第 3.3 节） | **未完成** |
| 位移效果（第 4 节） | **未完成** |
| 控制抗性递减（第 5.1 节） | **未完成** |

**打断与伤害数值彻底解耦**：旧模型比较的是「打断能力」这个浮点阈值，新模型比较的是等级。
单手剑普攻无论打出多高的数字都打不断遗迹守卫，这正是分级模型要表达的质感。

**霸体是覆盖而不是叠加**：霸体的语义是「这段时间内任何东西都打不断我」。
若改成与抗打断等级相加，一个本身抗打断为 0 的小怪进入霸体后仍可能被高等级攻击打断。

**两条事实而不是一个布尔字段**：订阅 `StaggeredEvent` 的是受击动画，订阅 `StaggerResistedEvent`
的是闪白与命中特效，两者没有共同的消费方。合成一条事件会迫使每个订阅者都写一次分支。

**字段位沿用带来的一处命名残留**：`EffectPropertyValue.Toughness`、`EffectTag.ToughnessGain`
与 `EffectSignalType.ToughnessGain` 保留旧名（枚举值是资产的序列化索引，不能重排），
但它们现在读写的是抗打断等级。`PropertyType.Toughness` 已停用，仅作占位。

## 3. 受击硬直

### 3.1 硬直时长

由受击动画长度决定，不额外配置数值。现有 `AttackedLogic` 的「受击状态严格跟随动画会话生命周期」设计正确，保留。

### 3.2 连续受击

- 硬直期间再次被打断 → 替换受击动画会话，**不退出受击状态**；
- 现有 `replacingPlayback` 机制已正确处理该边界，保留。

### 3.3 受击霸体（Hit Recovery）

为防止玩家被无限连，角色在连续受击若干次后短暂获得霸体【自定，原神未公开具体规则】。建议规则：

```text
2 秒内累计被打断 3 次 → 获得 1.5 秒霸体
```

该规则需在实机体验后调参。

## 4. 位移效果

### 4.1 击退

| 参数 | 说明 |
| --- | --- |
| 方向 | 攻击者指向目标的水平方向，或攻击段落指定的固定方向 |
| 距离 | 段落配置 |
| 曲线 | 快速起始、阻尼衰减 |
| 抗性 | 抗打断等级高于阈值的单位免疫击退 |

超载反应产生**强击退**，是其区别于其它剧变反应的关键特征。

### 4.2 击飞与浮空

部分强力攻击将目标击飞。浮空期间目标不可行动，落地产生额外硬直。多数精英怪与 Boss 免疫。

### 4.3 吸附与拉扯

风元素扩散、部分技能会产生吸附效果。吸附与击退互斥，同时存在时以后施加者为准。

## 5. 控制效果

| 效果 | 来源 | 表现 |
| --- | --- | --- |
| 冻结 | 水+冰 | 完全无法行动，可被碎冰解除 |
| 眩晕 | 特定技能 | 无法行动 |
| 石化 | 岩元素特定技能 | 无法行动，有独立耐久 |
| 定身 | 特定技能 | 无法位移，可转向与攻击 |
| 减速 | 冰附着、特定效果 | 移动速度降低 |

控制效果统一通过现有 `ControlStateModifier` 句柄机制施加与释放，不新建平行机制。

### 5.1 控制抗性递减

对同一目标反复施加同种控制时，有效时长逐次递减，防止无限控制：

```text
第 1 次：100%   第 2 次：70%   第 3 次：40%   第 4 次及以后：免疫
```

【自定】递减在 10 秒内无新控制时重置。

## 6. 受击表现

| 层 | 内容 |
| --- | --- |
| 动画 | 受击动画（可含恢复段），由 `AttackedExecutor` 驱动 |
| 材质 | 受击闪白，持续约 0.1 秒 |
| 特效 | 命中点 VFX，按伤害元素选择 |
| 音频 | 按武器类型 × 目标材质选择命中音 |
| 飘字 | 伤害数字，按元素与暴击区分样式 |
| 镜头 | 命中停顿与震屏，见 `09` |

## 7. 与现有实现的关系

保留：

- `AttackedLogic` 的动画会话绑定控制状态的设计；
- `replacingPlayback` 连续受击替换机制；
- `DieEvent` 后永久拒绝受击的处理；
- `ControlStateModifier` 句柄式贡献模型。

修改：

- `StaggeredEvent` 的产生条件从「打断能力 > 韧性」改为分级比较；
- `teamMemberComponent.IsOnField` 判断从「场外不播动画但仍结算伤害」改为「场外角色完全不受伤害」（见 `06` 第 4.1 节）。

## 8. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| H-01 | 单手剑普攻打丘丘人 | 打断成立，播放受击动画 |
| H-02 | 单手剑普攻打遗迹守卫 | 不打断，只有闪白与飘字 |
| H-03 | 元素爆发打精英怪 | 打断成立 |
| H-04 | 攻击带护盾的深渊法师 | 无论何种攻击都不打断 |
| H-05 | 硬直中再次被打断 | 受击动画替换，不出现状态闪断 |
| H-06 | 超载命中普通怪 | 产生强击退 |
| H-07 | 连续冻结同一目标 4 次 | 第 4 次免疫 |
| H-08 | DOT 伤害持续命中 | 不产生任何打断 |
| H-09 | 目标死亡瞬间受到攻击 | 不播放受击动画，伤害正常结算 |

H-01～H-03、H-08、H-09 的判定部分已由 `Prometheus.Effects.EditorTests` 覆盖；
H-04（护盾即霸体）需要敌人元素护盾与霸体联动，属排期第 7 步；
H-06（超载强击退）属第 4 节位移效果；H-07（连续冻结递减）属第 5.1 节控制抗性递减。
