# 程序化悬崖岩块（RockGen）

基于 ProBuilder 白盒块生成风格化悬崖岩块：顶面保持白盒原样（平整、可行走），侧面生成竖向节理与尖锥状凸起的切面。白盒块保留碰撞，生成的岩石只负责外观，玩法尺寸不受岩石凹凸影响。

当前进度：第 1 步（竖向节理 + 尖锥外凸；水平外凸、顶边倒角、转角避让 / 吸附、外凸限制修改器）。

## 使用

所有长度参数都是世界尺寸（米）：生成时先把白盒顶点乘以物体缩放再计算，输出时除回局部坐标。缩放白盒不会改变参数含义。

1. 白盒块需要有一圈顶环和一圈底环（见“算法”第 1 条）。用 ProBuilder 的 Poly Shape 画底面再拉伸即可；之后可以自由移动顶点、在顶面或底面的边上加点，顶面可以倾斜、侧面可以外倾或悬挑，侧面不要求是四边形。
2. 给白盒块添加 `CliffRockGenerator` 组件，调参数后点“生成岩石”。
   生成过一次后，开启 `livePreview`（默认开）时，在 Inspector 里改任何参数（包括拖动滑条、撤销 / 重做）都会自动用**预览流水线**重建网格：与默认流水线相同，只是把“出图”换成“复用上次的调试材质”，单次几毫秒到几十毫秒。预览不更新保存的图，确认效果后再点一次“生成岩石”完整更新。
3. 结果作为白盒块的子物体 `<名字>_Rock` 生成，是一个 ProBuilder 网格，可以继续用 ProBuilder 顶点工具手动微调。默认隐藏白盒块的渲染，保留其碰撞。
4. 相同种子和参数每次生成结果相同；改了白盒形状或参数，重新生成即可（会替换上一次的结果）。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `seed` | 1 | 随机种子 |
| `spacing` | 0.8 m | 撒点最小间距（压缩坐标下），决定节理岩板的宽度 |
| `verticalScale` | 0.35 | 纵向压缩系数：沃罗诺伊划分时高度乘以此值，只影响单元形状。越小单元边界越接近竖线，节理越竖直 |
| `verticalDensity` | 1 | 纵向散点密度系数：撒点时纵向间距除以此值，只影响纵向排几层。纵向间距 = `spacing / verticalScale / verticalDensity`；调大可避免节理从顶通到底 |
| `bulge` | 0.25 m | 散点处顶点外凸的基准距离（方向见“水平外凸”修改器） |
| `bulgeVariation` | 0.5 | 凸出量随噪声变化的幅度 |
| `cornerMargin` | 0.25 | 转角避让 / 吸附修改器：散点离侧面转角竖线的最小水平距离（spacing 的倍数），单元顶点离转角竖线小于其一半时吸附到线上。0 = 关闭 |
| `bulgeLimit` | 1 | 外凸限制修改器：锥顶凸出量 ≤ 系数 × 散点到单元边界 / 顶边 / 底边 / 转角竖线的最近距离；转角棱线顶点 Q 同理按到所在竖线段两端的距离限制 |
| `normalKeep` | 0 | 水平外凸修改器：外凸方向中保留侧面法线的比例。0 = 纯水平外凸（顶点高度不变，不会被抬过顶边），1 = 沿侧面法线 |
| `bevel` | 0 | 顶边倒角修改器：倒角面宽度（横截面里倒角斜边的长度）= 系数 × 平均侧面高度。0 = 不倒角。只作用于顶环。几何上放不下时自动等比缩小，日志写明实际宽度 |
| `bevelAngle` | 45° | 顶边倒角修改器：倒角面相对顶面的倾角。小于 45° 更平缓（风化磨圆感），大于 45° 更陡。外倾、悬挑侧壁也保持同样坡度 |
| `jointDepth` | 0.05 m | 单元边界（节理缝）顶点向内凹陷的最大距离；顶边、底边不凹陷 |
| `noiseScale` | 1.5 m | 噪声的特征尺度 |
| `textureMode` | Genshin | 贴图修改器：`Debug` = 侧面显示沃罗诺伊 ID 调试图（UV 与保存的图对应），其余灰色；`GrassRock` = 顶面草地，侧面、倒角、底面岩石；`Genshin` = 原神风格着色器（读顶点色，草地取 A 通道，只在顶面内） |
| `genshinMaterial` | 空 | Genshin 模式材质；为空时使用 `M_RockGen_Genshin` 并回填 |
| `grassMaterial` / `rockMaterial` | 空 | GrassRock 模式的草地 / 岩石材质；为空时使用 `Assets/Art/RockGen/Materials` 下的默认材质并回填 |
| `grassTileSize` / `rockTileSize` | 4 m / 8 m | 草地 / 岩石贴图一次平铺覆盖的世界尺寸 |
| `grassScatter` | 开 | 顶面撒草修改器：在顶面撒草叶（岩石的子物体 `<名字>_Grass`） |
| `grassDensity` | 30 /m² | 每平方米草叶数（只撒在纯草地上，即草地过渡带以内） |
| `grassHeight` | 0.45 m | 草叶基准高度，实际 0.7～1.3 倍；宽度为高度的 12%～20% |
| `grassBladeMaterial` | 空 | 草叶材质；为空时使用 `M_GT_Grass`（`Stylized/GenshinToon`，双面、带风动）并回填 |
| `mapWidth` | 1024 | 保存的图宽度（像素） |
| `normalMode` | Smooth | 法线平滑修改器：`Flat` = 平直着色（每个三角形一块均匀明暗）；`Smooth` = 全平滑（位置重合的顶点共享相邻面的平均法线，包括顶面、倒角面与侧面之间）；`Plates` = 岩板分区平滑（岩板内部平滑，节理缝、转角、顶面、倒角之间硬边） |
| `curvatureGain` | 1.2 | 顶点色烘焙：曲率增益，R = 0.5 + 曲率 × 增益 |
| `topJag` | 0.6 | 顶边扰动修改器：岩板顶部外凸量，单位为该岩板的凸出量。0 = 不外凸 |
| `topNotch` | 0.15 m | 顶边扰动修改器：节理与顶边交点处向内凹的深度。0 = 不内凹（白盒碰撞不随之内凹） |
| `topJagRound` | 关 | 顶边扰动修改器：峰点两侧各多插一点，轮廓更圆润 |
| `topSharpAngle` | 150° | 顶边锐角剪平：俯视顶边轮廓上外凸且夹角小于此值的尖点被剪平（切角：删去尖端，两条边上各取一点以直线相连），包括顶边扰动的峰点 / 圆润点与白盒顶环的凸转角；节理端点不参与。0 = 不剪平。顶边扰动有坡度限制，峰点夹角不小于 90° |
| `topSmoothStrength` | 0.5 | 顶边锐角剪平：越大切点离尖端越远，剪掉的越多。0 = 不剪平 |
| `topMinGap` | 0.5 m | 顶边点最小间距（展开带弧长）：顶环转角、节理与顶边的交点、峰点 / 圆润点相互间距都不小于此值，过近的节理交点会合并。0 = 不限制 |
| `grassBlend` | 1 m | 顶面草地过渡宽度：草地只在顶面内，从顶面外缘向内这段距离里由岩石线性过渡到草地，再往内全是草。0 = 整个顶面都是草 |
| `hideSource` | 开 | 生成后隐藏白盒渲染（碰撞保留） |
| `livePreview` | 开 | 实时预览：已生成过岩石时，改参数后自动用预览流水线重建网格（不出图） |

## 结构：修改器栈

`CliffRockBuilder` 中每个处理都是一个 `IRockStep`（修改器），按 `Pipeline()` 列表的顺序作用于共享的 `RockGenContext`。增加、移除或调换处理只需修改这个列表；`Generate(gen, pipeline)` 也可以传入自定义列表做对比实验。

| 顺序 | 修改器 | 作用 | 移除后 |
|---|---|---|---|
| 1 | `ScatterSeeds` | 周期泊松盘撒点（含纵向密度系数） | 必需 |
| 2 | `CornerSeedMargin` | 把离转角竖线过近的散点推开 | 转角处可能切出极窄碎块并翻折 |
| 3 | `CornerVertexSnap` | 改写单元顶点吸附场 `cellVertexSnap`：贴近转角竖线的单元顶点吸附到线上（必须在 `VoronoiCells` 之前） | 同上 |
| 4 | `VoronoiCells` | 沃罗诺伊划分（应用吸附场），插入断点 | 必需 |
| 5 | `TopEdgeMerge` | 合并顶边上间距 < `topMinGap` 的单元顶点（含转角的一方不动），只擦到顶边的小单元不再接触顶边 | 顶边点可能极近，稍加扰动就拧坏三角形 |
| 6 | `NoiseBulge` | 每个单元的凸出量 | 凸出量为 0 |
| 7 | `BulgeClamp` | 按散点到边界的距离限制凸出量；改写转角棱线外凸上限 `cornerBulgeLimit` | 贴边锥面可能被拉平或翻折 |
| 8 | `JointInset` | 改写节理深度场 `jointOf` | 节理深度为 0（无缝） |
| 9 | `HorizontalDisplace` | 改写外凸方向场 `displaceDir` 为水平方向 | 沿侧面外法线外凸 |
| 10 | `TopBevel` | 改写侧面映射场 `surfacePoint`（顶边下移）与顶面外缘场 `topRing`（顶面内收） | 直角顶边 |
| 11 | `TopEdgeJag` | 在单元顶边上插峰点；改写顶边偏移场 `topJag` / `topJagDir`，并把顶面外缘场 `topRing` 同步偏移（扰动前的外缘存入 `topRingSmooth`） | 直顶边 |
| 12 | `ConeFans` | 尖锥三角化（含跨转角处理） | 必需 |
| 13 | `Caps` | 顶面、底面封口；倒角带、草地过渡带逐顶环边拉链缝合；内环内部按白盒顶面折痕切块；记录每顶点草地权重 `grass` | 网格不闭合 |
| 14 | `WeldPositions` | 距离小于 0.5 mm 的顶点改为同一份坐标（与闭合校验的焊接精度一致） | 偶发浮点误差跨过焊接取整边界，产生假开口；亚毫米细缝两侧的点合并后细缝三角形塌缩为零面积 |
| 15 | `VertexColorBake` | 烘焙顶点色 `colors`：R 曲率、G AO、B 岩板色调、A 草地权重（取封口记录的 `grass`） | 不写顶点色，风格化着色器没有棱边 / 凹缝信息 |
| 16 | `ClosedCheck` | 闭合校验，写入日志 | 不校验 |
| 17 | `NormalSmoothing` | 按 `normalMode` 改写平滑组场 `smoothingGroupOf`（面 → ProBuilder 平滑组，0 = 硬边）；Plates 模式按共享顶点建分区邻接图，贪心着色分配组号 1～30 | 平直着色 |
| 18 | `SaveMapsStep` | 保存图与调试材质 | 不出图，侧面用灰色材质 |
| 19 | `TextureMapping` | 按 `textureMode` 改写贴图坐标、子网格场 `submeshOf` 与材质 `materials`（Genshin 模式两个子网格同一材质） | 调试纹理 |
| 20 | `OutputMesh` | 输出 ProBuilder 子物体（删除 output 引用与同名 `_Rock` 子物体后重建；把平滑组写到面上，由 ProBuilder 计算法线） | 不输出 |
| 21 | `TopGrass` | 在顶面封口三角形上按面积撒草叶，生成子物体 `<名字>_Grass` | 不撒草 |

实时预览用 `PreviewPipeline()`：默认流水线中的 `SaveMapsStep` 换成 `ReuseMaterial`（加载上次保存的 `M_RockGen_Debug.mat`），并且不调用 `AssetDatabase.SaveAssets()`。

上下文中的“场”都有默认值：外凸方向场 `displaceDir` 默认为侧面外法线，节理深度场 `jointOf` 默认为 0，侧面映射场 `surfacePoint` 默认为两环之间的直纹面，顶面外缘场 `topRing` 默认为原顶环，单元顶点吸附场 `cellVertexSnap` 默认不变，转角棱线外凸上限 `cornerBulgeLimit` 默认不限制。场修改器只包装 / 改写这些场，所以可以单独移除或叠加（后加入的修改器包在前一个之外）。

## 算法

1. **识别顶环与底环**：候选循环边为每个面的边界环，以及每个面与其近似共面（法线夹角小于 20°）的相连面合并后的外边界（顶面被细分成多块时也能整体识别）。顶环取顶点 y 值之和最大的候选，底环取最小的候选（并列时取顶点多者）。两环顶点数可以不同，但不能共用顶点。两环统一为俯视逆时针。顶环所围的面（白盒真实顶面，即碰撞体顶面）的三角形与其内部边（顶面不共面时的折痕）保存在 `Band.TopTris` / `Band.TopCreases`，`Band.TopHeight` / `OnTop` 按俯视位置取真实顶面高度（顶面外按最近三角形平面外推），顶面上所有生成的点都竖直投影到它上面。
2. **展开侧面**：以连接底环顶点与顶环顶点的边（竖边）为锚点；没有竖边时取离底环起点最近的顶环顶点作唯一锚点。锚点之间按弧长比例把两环一一对应，侧面视为两环之间的直纹面。`X` 为展开带上的距离（每段取底环段长与顶环段长的平均），`v` 为高度比例（0 底 → 1 顶）。两环的所有顶点都作为断点，生成时必须插入顶点，因此**两环上的顶点保持不动**，顶面、底面形态不变（开启顶边倒角时，顶环按倒角规则整体下移 / 内收，见第 7 条）。
3. **纵向稀疏撒点**：在坐标 `(X, Y · verticalDensity)` 上做 X 方向周期的泊松盘采样，再把纵坐标除回去（`Y = v · H · verticalScale`，`H` 为平均直纹线长度），纵向间距为横向的 `1 / (verticalScale · verticalDensity)` 倍。撒点密度与单元形状因此分开控制。离转角竖线小于 `cornerMargin × spacing` 的散点沿 X 推到该距离处（两条转角线太近时放在中点）。
4. **沃罗诺伊划分**：同一压缩坐标下的周期沃罗诺伊（Sutherland–Hodgman 半平面裁剪，含 X 方向 ±周长的副本）。单元顶点先经吸附场处理（离转角竖线小于 `0.5 × cornerMargin × spacing` 的顶点 X 吸附到线上），再在单元边与断点竖线（两环顶点对应的直纹线）的交点插入顶点。吸附必须在插入切点之前：相邻单元共享边吸附后完全一致，切点也一致，否则吸附点会和旧切点在竖线上折返。
5. **尖锥外凸**：每个单元以散点为锥顶做三角扇，锥顶沿外凸方向场凸出 `bulge × 噪声 × 单元大小`，再受外凸限制：不超过 `bulgeLimit ×` 散点到本单元边界、顶边、底边、转角竖线的最近世界距离（纵向距离 = 压缩坐标 / verticalScale），否则贴边散点的锥面会被拉平甚至翻折；单元边界顶点沿方向场反向内陷 `jointDepth × 噪声`，形成节理缝。方向场默认是侧面外法线；默认流水线中的“水平外凸”修改器把它投影到水平面（`normalKeep = 0`），这样斜面（法线带向上分量）上的锥顶不会被抬过对应的顶边。同一展开坐标的边界点只求值一次、所有单元复用，保证共享顶点坐标逐位相同。
   **绕序**：侧面三角形全部来自同一个展开平面，按展开坐标 (X, v) 中的绕序统一朝向（`AddSideTri`），朝外对应的是逆时针还是顺时针，由沿展开带均匀采样 32 处的 `∂X × ∂v` 与侧面外法线投票决定一次。不能逐个三角形用三维法线估计判断朝向：转角碎块、强外凸处估计会失误，单个三角形被翻转后与邻面绕序不一致，渲染时被背面剔除，看起来就是破洞。
6. **跨转角处理**：跨过断点竖线（侧面转角）的单元沿该线切成几块。转角线上取一点 Q（高度取散点高度），沿两侧方向场的平均方向外凸 `0.7 × bulge`（并受 `cornerBulgeLimit` 按 Q 到所在竖线段两端的距离限制），形成棱线；散点所在块以锥顶为中心，其余块以靠近散点一侧的 Q 为中心。避免三角扇“抄近路”把凸转角削成凹槽。
7. **顶边倒角**（`TopBevel`，可移除）：在每条直纹线垂直于顶边的横截面里，倒角面连接“顶面内收 `b` 的点”和“侧面顶边沿直纹线下移 `a` 的点”。
   - 倒角面宽度 `c = bevel × H`，倾角 `φ = bevelAngle`；`α` 为顶面内向方向与侧壁向下方向的夹角（竖直侧壁 90°）。由正弦定理 `b = c · sin(α + φ) / sin α`，`a = b · sin φ / sin(α + φ)`，所以外倾、悬挑侧壁的倒角坡度一样。
   - 直纹线相对顶边斜着走（两环顶点数不同时）时，`α` 用去掉沿边分量后的方向计算，沿直纹线的实际下移量 = `a / 直纹线方向垂直于顶边的分量`。
   - 每条顶边取一个内收量 `b`（用该边直纹线的平均 `α`），顶环转角按两侧不同内收量求斜接点；下移量按每条直纹线自己的 `α` 算，坡度处处为 `φ`。
   - 内向方向在顶面整体平面（Newell 法）内；外缘点（含两斜接点之间的插值点）再竖直投影到白盒真实顶面，保证外缘落在碰撞体顶面上。顶面不共面时坡度相对整体平面近似为 `φ`。不能改用每条边的局部扇面：中心低于边缘（帐篷形顶面）时外缘会低于侧面顶边，倒角面朝下翻转。
   - 约束：有效角度 ≤ `180° − α − 3°`（倒角不能比外倾侧壁还陡）；内收量 ≤ 顶面内切半径的 45%；沿直纹线下移量 ≤ 直纹线长的 25%。之后沿展开带采样 512 点加全部断点做合法性自检：倒角条带每个四边形朝向一致、外缘绕顶面中心单调前进（不自交、不折回）。不合法时宽度按 0.85 逐步等比缩小、角度不变（锐角转角 + 斜直纹线 + 不共面顶面叠加且倒角很宽时会触发），日志写明实际宽度与比例。
   - 侧面映射场沿直纹线把侧面压到 `[0, 1 − 下移量 / 直纹线长]`，节理与锥顶随之压缩、不会戳出倒角面。底环不受影响。
8. **封口**（面角色：顶面 `Top`、倒角面 `Bevel`、底面 `Bottom`；侧面三角形为 `Side`）：侧面顶边、底边上的顶点按展开顺序排成环，直接复用侧面三角形里的三维坐标（逐位一致）。顶面外缘取 `topRing`。
   - **倒角带**（外缘与侧面顶边不重合时）：逐条顶环边“拉链式”缝合——侧面顶边一段与外缘一段（都从转角 k 到 k+1）沿该边方向都是单调的（倒角下移只沿边滑动、顶边扰动只沿垂直于边偏移），按点在边方向上的投影归并两条链，每步推进投影较小的一侧。整段按自然顺序生成三角形后统一判定一次朝向（细长三角形的实际法线可能与平均法线相差 90° 以上，不能逐个判定）。
   - **顶面**：外缘 →（草地过渡带）→ 草地边界环 →（纯草带）→ 内环 →（内部）。三条点链都按同一参数 f（X → 所在顶环边与段内比例，相邻边上的点夹到段端）取样，并以 f 作为拉链缝合的归并键（不按三维投影归并：开倒角时侧面顶边沿斜直纹线滑动、顶面倾斜不共面，投影顺序会错乱）。
     - **草地边界环**（`grassBlend` > 0）：未扰动外缘多边形内缩 dG 的多边形 G 在同一 f 处取点，再叠加对 G 求值的顶边扰动 / 转角平滑水平偏移（`topOffsetFor(G, X)`：扰动量相同，转角曲线按 G 缩放）。草地边界因此与锯齿外缘平行，过渡带宽度处处约为 dG，**草地纹理的轮廓随 jag 后的顶面形状变化**；G 与外缘同参数化，点链沿边单调、不会折回。
     - **内环** I：未扰动外缘内缩 `blend + margin`（margin = max(最大内凹深度, 转角平滑最大内缩) + 0.1 m），受内缩上限（内切半径 45%）限制；dG = I 的实际内缩 − margin（不超过 `grassBlend`，顶面太小时过渡带变窄并写日志）。先定内环再让出 margin，避免两环都被上限截断而重合。内环点链加上与白盒顶面折痕的交点（端点 1 mm 内不插）。
     - **内部**：内环点链首尾相接，用白盒顶面每个三角形（俯视）裁剪，交点离边端点 ≤ 1 mm 时并入端点；每块相对中心是星形时中心扇，否则耳切（耳切共线判定用相对阈值、内部测试含边界）。内环不一定是凸多边形：顶面倾斜不共面或开倒角各边内收量不同时，近乎平直的顶环顶点俯视下可能是反角；也不能把内环凸化，反角处内缩量小时凸化后的内环会越过外缘。
     - 所有新点（内环点、交点、块中心、倒角外缘点）竖直投影到白盒真实顶面；PolyShape 的生成顶面与白盒顶面高度差由 0.33 m 降到 0，顶面最大折角 = 白盒自身折痕 8.6°。
   - 草地权重：外缘 0、内环 1（`grassBlend = 0` 时全为 1），顶点色在三角形内线性插值，环带内由岩石线性过渡到草地。底面直接以侧面底边为外缘做三角扇（假设顶面、底面为星形多边形）。封口与倒角面放在第二个子网格。
9. **贴图**（`TextureMapping`）：每个面记录角色。调试模式下侧面为子网格 0（调试材质），其余为子网格 1（灰色），侧面 UV0 = `(X / 周长, v)`，与保存的图一一对应。GrassRock 模式下顶面为子网格 1（草地），其余为子网格 0（岩石）；UV 按世界尺寸平铺：侧面 `(X, y) / rockTileSize`（沿侧面一圈连续、不随形状拉伸），顶面 `(x, z) / grassTileSize`，倒角面与底面按面法线主轴做盒状投影。
10. **顶点色**（`VertexColorBake`）：按位置焊接后取一环邻点，顶点法线为相邻面面积加权平均，`k = Σ dot(n, p − q) / Σ |p − q|`（凸为正、凹为负）。R = `0.5 + k × curvatureGain`；G = `1 − saturate(−k × curvatureGain × 2) × 0.6`；B 每块岩板一个哈希色调（0.5 ± 0.4，封口 0.5）；A 为封口记录的草地权重（顶面内 1、外缘 0、环带线性过渡，侧面 / 倒角 / 底面 0）。R、G、B 语义与 `Stylized/GenshinRock` 一致（R 0.55 以上提亮棱边、0.45 以下压暗凹缝，G 乘 AO，B 调色调）；A 由 `RockGen/GenshinCliff` 读取，与岩石颜色线性混合。全平滑法线下顶边法线会被侧面平均，按法线判断长草会蔓延到侧面，所以草地必须由几何决定。
11. **校验**：按位置焊接后统计每条边被几个三角形共用（两顶点重合的零面积三角形跳过），结果写入日志；正常应为开口边 0、非流形边 0。排查破洞时还应检查同向重复边（同一条有向边出现两次 = 相邻三角形绕序不一致）。

## 顶边扰动（`TopEdgeJag`）

让顶边轮廓顺应侧面节理：岩板顶部外凸、节理处内凹，俯视呈锯齿状；顶环转角不动。

1. **插点**：每个摸到顶边的单元，其顶边段被转角竖线分成若干小段；长度 ≥ 2 × `topMinGap` 的小段插一个峰点（含散点 X 的小段取散点 X，夹在小段中间 50% 且离两端 ≥ `topMinGap` 的范围内，其余取中点），`topJagRound` 时峰点到某端 ≥ 2 × `topMinGap` 才在该侧再插一点。顶边段只属于一个单元，插点不会产生 T 形接缝。

   顶边点的来源与间距保证：
   | 来源 | 产生位置 | 间距保证 |
   |---|---|---|
   | 顶环转角 | `VoronoiCells` 在转角竖线上插的切点 | 固定（白盒决定），合并时不动 |
   | 节理交点 | 沃罗诺伊单元边与顶边的交点 | `CornerVertexSnap` 吸附贴近转角的点；`TopEdgeMerge` 反复合并最近一对间距 < `topMinGap` 的点（含转角的一方不动，否则按点数加权取中点） |
   | 峰点 / 圆润点 | `TopEdgeJag` | 小段短于 2 × `topMinGap` 不插峰点；峰点、圆润点离两端 ≥ `topMinGap` |

   合并只沿顶边水平移动单元顶点，共享同一 X 的相邻单元同步更新，不产生裂缝。验证：`topMinGap` = 0.5 / 1.0 m 时三块白盒顶边最小间距恰为 ≥ 设定值（不限制时 PolyShape 最近 0.06 m）。
2. **偏移量**：峰点外凸 `topJag × 该岩板凸出量`，且不超过到小段较近端点距离的一半；节理端点内凹 `topNotch`；转角为 0；圆润点取端点与峰值之间 75% 处。之后所有控制点做**坡度限制**：偏移不超过到相邻控制点较近距离的一半（相邻控制点之间坡度 ≤ 1）。节理内凹是固定值，离下一个控制点很近时轮廓会陡到 2:1 以上，顶边附近的侧面三角形被横向拧翻——这是调试中翻面的主要原因。
3. **锐角剪平**（坡度限制之后、插入单元之前）：本修改器插的点（峰点 / 圆润点）中，俯视轮廓上外凸且夹角 < `topSharpAngle` 的尖点被删去，改为两条边上各一点：在 (X, 偏移) 平面（直边上即俯视平面）取 A = 尖点向左邻点走 s、B = 向右邻点走 s（s = 0.45 × `topSmoothStrength`，两侧互不重叠），A、B 之间为直线（切角）。剪平点不受 `topMinGap` 限制。为此本修改器先收集全部控制点，做完坡度限制与剪平后才把点插入所属单元。
   **顶环转角剪平（拓扑剪平）**：俯视夹角 < `topSharpAngle` 的白盒凸转角，半宽 `a = 0.45 × topSmoothStrength × min(两侧顶环边的 X 长度, 2 × spacing)`（相邻转角互不重叠）。剪平区在规划峰点之前算出：区内不插峰点，区内的控制点（转角、节理端点）不参与偏移插值；只在与转角相连的两条顶边上插入切点 A（Xc − a）、B（Xc + a），区间写入 `topChamfers`。偏移场在区内取 A、B（各含扰动）的连线，与实际顶边一致；封口的草地边界链在 A / B 处按其 X 在 G 上取样（G 也被剪平，尖角不会越过外缘剪平线）。剪平使外缘向内的最大垂直距离 `0.5 · a · sin θ` 写入 `topCornerInward`，封口内环内缩不小于它 + 0.1 m。
   拓扑在 ConeFans 里完成：各单元按转角竖线切块、插 Q 之后，区内顶边顶点吸附到切点（转角左侧 → A，右侧 → B，转角点本身默认归 B），去掉相邻重复点。原转角点消失，A–B 直接相连，原来连到转角的转角竖线（Q → 转角）、连到区内顶点的节理线改接到切点上。吸附前对所有块做一遍预检：吸附后某块在展开平面上自相交或翻转（例如节理折点落在斜线 Q → B 上方），或全局铺砌不一致（所有块的内部有向边应恰好正反各一次；同向重复 = 两块重叠，缺反向 = 缝隙，吸附前已存在的冲突边不计）时，该转角改为转角点归 A；仍不行则该转角不吸附（区内顶点保留，按偏移场落在 A–B 连线上，几何上仍是剪平的），日志输出各转角的处理方式。吸附后块不一定从原扇心可见（散点落在让出去的三角区、或块出现反角）：扇心依次试散点 / Q、本块两侧的 Q、在吸附前 X 范围内网格搜索星形核内离散点最近的点，都不行时在展开平面上耳切这一块。曾用“区内点线性映射到 A–B 上、保留转角点”的做法，转角点与区内顶点都还在，尖锥处拓扑不干净，已改为吸附。验证：三块白盒 × 倒角 {0, 0.0343} × 外凸 {0, 0.6, 1.5} × 内凹 {0, 0.5} × 草地过渡 {0, 1, 2} × 强度 {0.3, 1}（阈值 170°）共 216 组全部合法（强度 1 时 PolyShape (1) 有 2 处转角改归 A，没有出现不吸附）。之后在蒙德 blockout 的 39 块高台 / 台地崖壁白盒（高 5～40 m，散点间距 3.5 m）上发现逐块检查漏掉的重叠（两块吸附后都占了同一块三角区），加入全局铺砌检查后：39 块 × 4 组参数（含阈值 170°、强度 1、倒角 0.0343）共 156 组全部闭合，部分转角退为归 A 或不吸附。
4. **偏移方向**：水平部分垂直于该处所在的顶环边、朝外；再加上白盒真实顶面在新旧位置的高度差（斜顶面上外凸的点随坡面升降，否则顶边出现台阶），侧面顶边点与外缘点用同一偏移向量 `topJagOffset`。不能用侧面外法线场：转角附近外法线是两侧平均、斜着指，相邻点偏移带沿边分量会交叉；同一直边上的点沿同一方向偏移，顺序不变。
5. **跟随**：尖锥三角化时顶边上的边界点叠加偏移；顶面外缘场同步偏移，倒角带、草地内环随之跟随。

验证：三块白盒 × 倒角 {0, 0.0212, 0.06, 0.15} × 外凸 {0, 0.6, 1.0, 1.5} × 内凹 {0, 0.15, 0.5} × 圆润 × 草地过渡 {0, 1}，PolyShape (1)、(2) 全部 192 组合法（无开口边、非流形边、退化面、反面），PolyShape 仅倒角 0.15 的组合有问题（见“限制与后续”）。

## 顶面撒草（`TopGrass`）

放在 `OutputMesh` 之后，在顶面封口三角形（角色 `Top`）上撒草叶，生成岩石的子物体 `<名字>_Grass`（随岩石一起删除重建，不投影）。

- 数量 = 三角形面积 × `grassDensity`，位置为三角形内均匀随机点；随机数以 `seed` 为种子。
- 只在纯草地上撒：三个顶点草地权重都为 1 的三角形（草地过渡带的内环以内），过渡带与岩石上不撒。
- 草叶与 `GenshinTerrain` 相同：5 顶点弯折叶片，法线朝上；顶点色 RGB = 线性固有色（根部取悬崖材质的 `_GrassDeep` ↔ `_GrassLight` 按大尺度噪声插值并压暗 12%，叶尖偏亮黄绿），A = 风动权重（根 0 → 尖 1）。
- 实时预览同样生成，三块岩石 2.7k～5.5k 株，预览 30～150 ms。
- 草叶生成函数 `RockGenGround.AddBlade` 与地面撒草共用。

## 地面（`RockGenGround`）

挂在场景地面（平面网格）上，地面材质用 `RockGen/GenshinCliff` 并开启 `_GroundMode`（示例：`Assets/Art/VFX/Slash/Materials/M_PreviewGround_Grass.mat`），让地面与岩顶草地同一风格、同一清晰度，并在岩石周围加接触 AO。

- **撒草**：在场景里所有岩石的包围范围外扩 `margin`（默认 20 m）的矩形内，按与岩顶相同的密度（`grassDensity` 30 /m²）、高度、草色（取岩石悬崖材质的草色）撒草叶，按 `chunkSize`（16 m）分块成多个网格便于视锥剔除。岩石脚下（占地遮罩内）不撒。地面只有着色器颜色时远看发糊，清晰度来自草叶。
- **接触 AO**：每块岩石离岩底 `aoHeight`（1.5 m）以内的三角形按高度裁剪后俯视投影（含外凸岩板；只用底面时 AO 大半被上方外凸遮住，看不出来），光栅化成占地遮罩（`aoTexel` 0.2 m/像素），两遍 chamfer 距离变换得到到轮廓的水平距离 d，`ao = 1 − aoStrength × (1 − smoothstep(0, aoRadius, d))`（默认强度 0.65、半径 4 m）。烘成贴图经 MaterialPropertyBlock 交给地面着色器；草叶根部 × ao、叶尖 × lerp(1, ao, 0.75)。
- **生命周期**：生成的网格、贴图都是 `HideAndDontSave`，不存进场景；组件启用时（打开场景、脚本重载、进入运行）按种子确定性重建，约 1 s（三块岩石、26 万株）。岩石点“生成岩石”后自动刷新；只移动岩石时用组件右键菜单“重建”。

## 原神风格着色器（`RockGen/GenshinCliff`）

输入：顶点色 R 曲率、G AO、A 草地权重（B 岩板色调本着色器不用）；UV0.y 相对高度（Genshin 贴图映射写入：侧面 0 底 → 1 顶，顶面与倒角 1，底面 0；UV0.x 为展开带弧长，备用）。所有尺度参数以米为单位，按悬崖尺度取值。

| 层 | 做法 | 主要参数 |
|---|---|---|
| 岩石底色 | 亮 / 暗两色按高度渐变（上浅下深），不叠噪声杂色（大色块、岩板色调、岩层带、风化条纹试过后去掉） | `_RockLight` `_RockDark` `_HeightGrad` |
| 棱边 / 凹缝 | R > 0.55 提亮、R < 0.45 压暗；屏幕空间法线变化率补细棱线 | `_EdgeHighlight` `_CavityDark` `_EdgeLine` `_EdgeLineSharp` |
| 顶边亮带 | 侧面相对高度最上方一段与倒角提亮，不压到草上 | `_LipHighlight` `_LipWidth` |
| 草地 | 与岩石按 A 混合；`_GrassSquare` 开启（默认）时用 A² 平方平滑，靠近岩石一侧草地淡入更慢、过渡更柔和；草色在水平面上大尺度黄绿 ↔ 蓝绿变化，叠细碎斑点 | `_GrassSquare` `_GrassDeep` `_GrassLight` `_GrassScale` `_GrassSpeckle` `_GrassSpeckleScale` |
| 接地 / AO | 物体原点以上 `_ContactHeight` 米内按 smoothstep 渐暗，岩脚压暗 `_ContactDark`（`M_RockGen_Genshin` 取 0.5）；乘顶点 AO | `_ContactHeight` `_ContactDark` |
| 地面模式 | `_GroundMode` 开启时忽略顶点色：整面纯草地、平坦、无 AO、无接触压暗，用于场景地面；再乘 `RockGenGround` 通过 MaterialPropertyBlock 设置的接触 AO 贴图（`_ContactAOTex`，俯视矩形 `_ContactAORect` = (x0, z0, 1/宽, 1/高)，矩形外为 1） | `_GroundMode` |
| 光照 | 半兰伯特 → 两档渐变，暗部乘冷色阴影色；亮部窄高光带、轮廓光、少量球谐环境光 | `_ShadowTint` `_RampMid` `_RampSoft` `_HighlightStrength` `_ShadowStrength` `_RimColor` `_RimStrength` |

**低模上的“硬边”**：全平滑时同一位置的顶点法线完全一致，但三角形内法线是线性插值的，相邻三角形之间法线的变化率不连续；卡通渐变（`_RampSoft` 很窄）会把明暗交界放大成沿三角形边走的折线，锥面上表现为从锥顶放射出的棱线，看起来像硬边。渐变放宽（如 0.3）后基本消失。根治需要让法线场更平缓（法线平滑 / 从平滑代理体转移法线）或增加面数。

曲率增益不宜过大：锥面顶点（锥顶）是强凸点，顶点色在整个三角形内插值，增益过大时棱边提亮会铺满锥面，岩体整体发白。

## 切削岩石（`FacetRockGenerator`）

与悬崖生成器完全独立的第二种岩石：把任意网格的凸包当作原石，用多组平面切削，得到大块平整 facet 组成的低模岩石。没有顶面草地、不考虑碰撞体、不做岩底切平；输出普通 Mesh（不是 ProBuilder，法线与 UV1/UV2 完全由生成器控制），作为子物体 `<名字>_FacetRock`，点“生成岩石”时网格保存到 `Generated/<名字>_<种子>/FacetRock.asset`，实时预览不保存。

**流程**（`FacetRockBuilder`，世界尺寸计算）：

1. 原石：源网格顶点的增量凸包，共面三角形合并成凸多边形 facet。非凸网格的凹处会被抹平。
2. 大刀 `bigCuts`：方向为 Fibonacci 球面均匀分布 + 随机整体旋转 + `bigJitter` 抖动，在“该方向上原石最突出处 − 切深 `bigDepth`”处切一刀，保留内侧。
3. 崩口 `chipCuts`：按尖锐度（顶点处各面单位法线平均值的长度越小越尖，按 (1 − |a|)² 加权）随机选顶点，沿其平均法线 + `chipJitter` 抖动的方向切掉它，切深 `chipDepth`。
4. 每刀的质量约束：新产生的边 ≥ `minEdge`、切面与相邻面的转角 ≥ `minAngle`（否则近乎共面成碎面）、剩余体积 ≥ 切前 30%；不满足时重新随机方向与切深，最多 8 次，仍不行跳过这一刀（日志里的“跳过”）。
5. 单刀 = 半空间裁剪：顶点到平面距离 < 0.1 mm 时吸附到平面；每个面逐边裁剪，同一条边的交点按端点对缓存、相邻面共用；切口点按平面内极角排成逆时针补成新面。凸体与半空间的交仍是凸体，每一步都闭合。最后去掉只属于两个面的共线点。

**法线平滑**（`normalSmoothWidth`，默认 0.3 m）：每条棱两侧这个距离内法线从 facet 法线过渡到棱的平分法线，带外 facet 保持平整；不用法线贴图。原始低模上只靠顶点法线做不到——一个 facet 三角形从一条棱跨到另一条棱，顶点法线会把整个 facet 抹成弧面——所以几何上先插支撑环划出平滑带，过渡曲线交给着色器：

- 每个 facet（凸 k 边形）：每条棱两端各往里 `s = min(W, 棱长/3)` 插棱上点（只由棱决定，两侧 facet 一致，无 T 形接缝）；两条相邻棱各自向内平移 `s` 的交点构成内缩环（到两条棱的距离正好是各自的平滑宽度），内缩环翻转、越过其他棱的平移线或出现短于 2 mm 的边时整体收窄（×0.8 重试，日志里的“收窄”）；三角形 = 内缩环扇形 + 每条棱一条带 + 每个转角一块。一个 k 边形约 5k − 2 个三角形。
- 顶点属性：UV1 = (facet 法线, t)，t 在棱上点与转角为 1、内缩环为 0——棱带的两个三角形里 t 正好是 1 − 到棱距离 / 宽度；UV2 = t × 目标法线（棱上点为两侧 facet 法线平分方向，转角为按内角加权的顶点法线，内缩环为 0），插值后归一化即目标方向，t → 0 时自然没有权重，转角块与棱带共边处属性一致、无接缝。网格自带法线 = 按 t 线性混合的近似（阴影偏移与其他着色器退化使用）。
- 着色器 `RockGen/FacetRock`：法线 = slerp(Nf, Nt, p)，`_Profile` 选过渡曲线——Round（默认，与 facet 相切的等半径圆弧：p = asin(t · sin h) / h，h 为 Nf 与 Nt 夹角）、Smooth（smoothstep）、Linear；`_EdgeHighlight` 按 p 提亮棱边。固有色亮 / 暗按相对高度（顶点色 G）渐变，`_FacetTone` 按每个 facet 的随机色调（顶点色 R）微调，色调在平滑带内按 1 − p 淡出（棱上两侧都回到中性；不淡出时两侧色调不同，棱上亮度跳变，平滑后仍读成硬边。任何按 facet 取值、在棱上不连续的量都要这样处理）；光照与 `GenshinCliff` 相同。UV0 为每个 facet 平面内的世界尺寸投影 / `uvTileSize`（备用）。
- 只改明暗、不改位置：剪影仍是折线。几何倒角（剪影变圆）暂不做。

**验证**：8×6×10 m 立方体与 Cylinder、PolyShape、PolyShape (1) 白盒四种原石 × 种子 1～15 × 刀数 {(4, 6), (10, 20), (24, 60)} × 平滑宽度 {0, 0.3, 1.5} 共 540 组全部闭合、无非流形边、无朝内三角形；单次 22～29 ms。闭合校验在世界尺寸下焊接（局部坐标在大缩放下会把相距几毫米的点焊成一点，误报非流形边）。

## 限制与后续

- 底面封口仍用中心三角扇，凹度较大的底面轮廓可能出错。
- PolyShape（顶面倾斜不共面、接缝处有 178.9° 的近平直反角顶点）在倒角系数 0.06 且草地过渡宽度 ≥ 1 m 时，内环在该顶点处会出现几厘米的外凸毛刺，与折痕裁剪后形成自交块，有少量翻面；倒角 ≤ 0.0343（当前场景值）时全部合法，PolyShape (1)、(2) 全部合法。
- PolyShape（顶 5 点 / 底 4 点、顶面不共面、锐角转角）在倒角系数 0.15 且有顶面内环时有少量翻面（与顶边扰动无关，倒角自身已被限制缩小到 61%）；倒角 ≤ 0.06 时全部参数组合合法。
- 实时预览只响应 Inspector 参数修改与撤销 / 重做；移动白盒顶点后需要手动点“生成岩石”。
- 原神风格（Genshin 模式）后续：悬崖尺度的风化条纹、草色大尺度变化与顶边草帘、加强顶边高光（渲染方案第 2 步）；顶面散草、底部碎石（第 3 步）；场景后处理与雾（第 4 步）。
- 后续步骤：层理与更多不规则（第 2 步）、倒角与曲率顶点色并接入 `Stylized/GenshinRock` 着色器（第 3 步）、接入开局区白盒（第 4 步）。
