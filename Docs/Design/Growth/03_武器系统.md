# 03 武器系统

## 1. 设计目标

武器是**可交换、可复用**的养成载体：同一把武器可以在角色之间转移，因此它的养成投入不绑定在某个角色身上。它贡献三样东西——基础攻击力（进 Base 通道，被百分比放大）、一条副属性、一个被动技能。精炼则是武器版的命之座：由重复获得驱动，只增强被动。

## 2. 武器分类

| 维度 | 取值 |
| --- | --- |
| 类型 | 单手剑 / 双手剑 / 长柄武器 / 弓 / 法器 |
| 星级 | 1★ ~ 5★ |

**武器类型必须与角色的武器类型匹配**才能装备。类型同时决定普攻连段与重击形态，见 [Combat/02 攻击与连段](../Combat/02_攻击与连段.md)。

## 3. 等级与突破

### 3.1 等级上限

| 星级 | 最高等级 | 突破次数 |
| --- | --- | --- |
| 1★ / 2★ | 70 | 4 |
| 3★ | 70 | 4 |
| 4★ / 5★ | 90 | 6 |
【待复核】

4★/5★ 的突破阶段与角色完全一致（20/40/50/60/70/80 六个闸门），因此武器与角色可以同步推进。

### 3.2 基础攻击力

```text
武器基础攻击力(等级, 突破阶段) = 一级基攻 × 曲线系数(等级) + 突破固定加值(突破阶段)
```

结构与角色基础属性完全同构（见 [01 第 2.2 节](01_角色等级与突破.md)），只是曲线与加值另配一套表。

**武器基攻写入 `Atk` 的 Base 通道，与角色基攻相加**。这是它区别于所有其它攻击力来源的地方：固定攻击力词条进 Flat 通道，不被百分比放大；武器基攻进 Base 通道，被放大。

### 3.3 副属性

- 每把武器有 **0 或 1 条**副属性，类型固定不变。
- 1★/2★ 武器通常没有副属性。
- 副属性的**初始值与成长曲线**由武器决定，数值随等级与突破提升。
- 可选类型与角色第二属性同池（见 [01 第 3.3 节](01_角色等级与突破.md)），落点同样是 [Combat/05A](../Combat/05A_属性位清单.md) 的既有属性位，本案不新增。

### 3.4 经验与消耗

| 类别 | 说明 |
| --- | --- |
| 武器经验 | 精锻用魔矿 / 精锻用良矿 / 精锻用杂矿，三个品阶 |
| 武器本身 | 可直接吞噬其它武器转为经验，按星级折算 |
| 摩拉 | 升级与突破均消耗 |
| 突破材料 | 武器秘境材料（四品阶，**按星期开放**）+ 两类怪物掉落 |

武器秘境与天赋秘境一样按星期开放，两者开放日**错开**，这样每天至少有一条养成线可推。

## 4. 精炼

### 4.1 规则

- 精炼等级 `R1 ~ R5`，初始 R1。
- 消耗**同名武器**或对应的精锻素材。
- 每次精炼消耗 1 份，R1→R5 共需 4 份（即 5 把同名武器）。
- 精炼**只增强被动技能**，不影响基础攻击力与副属性。
- 不可重置、不可转移。

### 4.2 被动技能

- 每把武器 0 或 1 个被动（1★/2★ 通常没有）。
- 被动效果的**数值随精炼等级提升**，机制不变——例如「攻击力提升 20/25/30/35/40%」。
- 被动由 `EffectDefinition` 承载，精炼等级作为效果的数值档位索引。

### 4.3 与命之座的对比

| | 命之座 | 精炼 |
| --- | --- | --- |
| 载体 | 角色 | 武器 |
| 层数 | 6 | 5 |
| 来源 | 重复获得同名角色 | 重复获得同名武器 |
| 作用 | 机制 + 天赋等级 | 仅被动数值 |
| 可转移 | 否 | 随武器转移 |

**精炼跟着武器走**：把 R5 武器换给另一个角色，精炼等级不变。这是武器相对命座的核心优势，也是武器可以在队伍内流转的原因。

## 5. 装备规则

- 一个角色同时装备 1 把武器。
- 一把武器同时只能装备在 1 个角色上。
- 把已装备的武器换给另一个角色时，原角色自动卸下（变为无武器或提示替换）。
- 角色不可处于无武器状态上场——初始装备该类型的 1★ 保底武器。

## 6. 配表

### 6.1 `WeaponBase`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `weaponId` | string | 主键 |
| `nameKey` / `descKey` | string | 本地化 key |

## 7. 与现有实现的差异

| 项 | 现状 | 目标 |
| --- | --- | --- |
| 武器身份 | `WeaponConfig` 同时是 Definition 与成长配置，角色固定一把 | 独立 `WeaponBase` 表，武器可在角色间转移 |
| 等级 | `AnimationCurve` 映射归一化经验 | 逐级经验表 |
| 突破 | **不存在** | 4 或 6 阶段 |
| 基础攻击力 | 由词条提供，进 Offset / Boost 通道 | 进 `Atk` 的 **Base** 通道 |
| 副属性 | 用通用词条（`TierInstance`）表达 | 单独一条，类型固定，按曲线成长 |
| 精炼 | **不存在** | R1–R5，只影响被动 |
| 被动技能 | **不存在** | `EffectDefinition` + 精炼档位 |

现有 README 已自行指出「`WeaponConfig` 同时承担 Definition 与成长配置，后续允许换武器时应拆分」——本案确认这个拆分是必须的，且武器必须可转移。

**通道语义的改动最容易被忽略**：现有实现把武器提供的攻击力当作词条（Offset/Boost），目标是把**基础攻击力**放进 Base 通道、把**副属性**放进对应属性位。两者数值上不等价，改造时必须同步重算配置。

## 8. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| W-01 | 单手剑角色装备长柄武器 | 拒绝，提示类型不匹配 |
| W-02 | 武器基攻 608，角色攻击力% 50% | 武器基攻参与百分比放大 |
| W-03 | 3★ 武器升级 | 停在 Lv70，无第 5/6 次突破 |
| W-04 | 武器突破 | 等级不变，上限抬高，基攻加值生效 |
| W-05 | 吞噬另一把武器 | 按星级折算为武器经验 |
| W-06 | R1→R2 精炼 | 消耗 1 份同名武器，被动数值切到第 2 档 |
| W-07 | R5 武器换给其它角色 | 精炼等级保持 R5 |
| W-08 | 装备已被占用的武器 | 原角色自动卸下 |
| W-09 | 无副属性的 1★ 武器 | 不写入任何属性位 |
| W-10 | 武器秘境在错误星期 | 该品阶材料不产出 |
