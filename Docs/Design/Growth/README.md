- 属性位清单与聚合规则：[Combat/05A_属性位清单](../Combat/05A_属性位清单.md)

## 核心结论

原神养成设计的三个不可替代特征，复刻时必须保留：

1. **突破是等级的闸门，不是等级的一部分**。等级到达阶段上限后必须消耗材料突破才能继续升级，而突破同时解锁固有天赋、抬高天赋等级上限、并按档位提供第二属性。这让养成节奏由材料获取而非经验堆积决定。
2. **圣遗物是随机的，其余四条线是确定的**。等级、突破、天赋、命座、武器精炼全部按表推进，只有圣遗物引入主副词条随机与强化随机。这条唯一的随机线承担了长期留存，其余线承担确定的成长预期。
3. **树脂是所有养成线的共同瓶颈**。角色突破素材、天赋书、武器材料、圣遗物、经验书与摩拉全部消耗树脂，因此「今天练谁」是一个真实的取舍，而不是并行推进。
