# 07 好感度与角色档案

## 1. 设计目标

好感度是**唯一不影响战斗力的养成线**。它存在的意义是给角色以「被使用过」的痕迹：玩家把某个角色带久了，会解锁关于这个角色的内容。它必须与战力彻底解耦——一旦好感提供属性，它就变成又一条必须刷的日常，而不是自然积累的记录。

## 2. 好感等级

| 项 | 值 |
| --- | --- |
| 等级范围 | 1 – 10 |
| 初始 | Lv1，0 经验 |
| 满级 | Lv10 |
【实测】

好感等级不影响任何战斗属性、不影响任何天赋、不参与任何面板计算。

## 3. 好感经验来源

| 来源 | 说明 |
| --- | --- |
| 每日委托 | 完成全部委托后，队伍中**上场过的角色**获得好感经验 |
| 秘境 / 周本 | 完成后队伍全员获得 |
| 任务 | 部分任务给予特定角色好感 |
| 小道具 | 提供好感经验的消耗品 |

**只有队伍中的角色获得好感经验**，因此好感天然记录了「你常带谁」。这个语义要保留：不要做成可以对任意角色直接投喂的资源。

## 4. 好感奖励

| 好感等级 | 解锁 |
| --- | --- |
| 逐级 | 角色档案的资料条目 |
| 中段 | 角色语音条目 |
| Lv10 | **角色名片** + 全部档案条目 |
【待复核】各档位解锁的具体条目需逐角色确认。

奖励全部是**展示性内容**，无战力产出。

## 5. 角色档案

角色档案是好感度的内容载体，包含：

| 分类 | 内容 | 解锁方式 |
| --- | --- | --- |
| 资料 | 角色背景文本，分若干条 | 好感等级 |
| 故事 | 角色故事，分若干条 | 好感等级 + 部分需完成传说任务 |
| 语音 | 角色语音，分若干条 | 好感等级 |
| 特殊料理 | 角色专属料理 | 固定，角色获得时即有 |
| 命之座图鉴 | 命座名与效果 | 命座解锁状态 |

档案内容属于叙事资产，由 `NarrativeSystem` 的文本管线承载，不在养成模块内重复建表——本案只定义解锁条件，文本存放遵循 `Assets/Prometheus/Gameplay/NarrativeSystem/` 的既有约定。

## 6. 配表

### 6.1 `FriendshipLevel`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `level` | int | 主键，1–10 |
| `expToNext` | int | 升到下一级所需好感经验；10 级填 0 |

全角色共用一条好感经验曲线，不按角色区分。

### 6.2 `CharacterProfile`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `characterId` | string | 主键之一 |
| `entryId` | string | 主键之一，条目 ID |
| `category` | ProfileCategory | `Info` / `Story` / `Voice` / `Dish` / `Constellation` |
| `textKey` | string | 文本本地化 key |
| `unlockFriendship` | int | 所需好感等级；0 表示初始解锁 |
| `unlockQuestId` | string | 额外要求完成的任务；无则留空 |
| `sortOrder` | int | 展示顺序 |

## 7. 与现有实现的差异

现有实现**完全没有好感度与角色档案**。需要新增：

| 模块 | 说明 |
| --- | --- |
| 好感度状态 | 账号级，按 `characterId` 存 `{ level, exp }` |
| 好感经验发放 | 每日委托、秘境、周本结算时对队伍成员发放 |
| 角色档案 UI | 展示解锁状态与文本 |
| 名片 | 账号级收集物，与 UI 展示层对接 |

实现上好感度**不进入 `PropertyComponent`、不产生任何 Effect**——它没有属性产出，走 Effect 投影只会污染属性链路。它是一份纯数据 + 一个解锁查询接口。

## 8. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| F-01 | 完成每日委托 | 队伍中上场过的角色获得好感经验 |
| F-02 | 未上场的队伍成员 | 按发放规则处理，与上场成员区分 |
| F-03 | 好感升级 | 解锁对应档案条目 |
| F-04 | 好感 Lv10 | 解锁角色名片 |
| F-05 | 好感等级变化 | 角色面板属性**完全不变** |
| F-06 | 需要传说任务的档案条目 | 好感够但任务未完成时仍锁定 |
| F-07 | 好感满级后继续获得经验 | 不溢出报错，经验不再累积 |
