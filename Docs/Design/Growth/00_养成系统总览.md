# 00 角色养成系统总览

## 1. 设计目标

养成系统要同时满足三件事：**确定的长期目标**（玩家知道练到什么程度需要多久）、**每日的取舍**（资源有限，今天推哪条线是真实决策）、**不封顶的追求**（圣遗物让顶端玩家永远有事可做）。原神用「五条养成线 + 一个共同瓶颈」达成这三点，复刻时这个结构不能拆。

## 2. 五条养成线

| 线 | 载体 | 上限 | 随机性 | 主要消耗 |
| --- | --- | --- | --- | --- |
| 角色等级与突破 | 角色 | Lv90 / 六阶突破 | 无 | 经验书、摩拉、突破素材、地方特产 |
| 天赋 | 角色的三个天赋 | Lv10（命座可至 15） | 无 | 天赋书、怪物掉落、周本材料、摩拉 |
| 命之座 | 角色 | 6 命 | 抽卡获得 | 同名角色 / 命座石 |
| 武器 | 武器 | Lv90 / 精炼 5 | 无 | 武器经验、摩拉、武器突破素材 |
| 圣遗物 | 5 个部位 | Lv20 / 5★ | **有** | 圣遗物经验、摩拉 |

**只有圣遗物一条线是随机的**。其余四条全部按表推进，玩家可以精确预期。这条唯一的随机线承担长期留存，其余承担确定的成长预期——复刻时不要给其它线加随机，也不要把圣遗物的随机去掉。

## 3. 资源闭环

```text
                      ┌──────────────┐
                      │  原粹树脂    │ ← 每 8 分钟恢复 1 点，上限 160
                      └──────┬───────┘
                             │ 消耗
       ┌──────────┬──────────┼──────────┬──────────────┐
       ▼          ▼          ▼          ▼              ▼
   世界 Boss   天赋秘境   武器秘境   圣遗物秘境      地脉花
  角色突破素材  天赋书    武器材料    圣遗物      摩拉 / 经验书
       │          │          │          │              │
       └──────────┴──────────┴──────────┴──────────────┘
                             │
                             ▼
                        角色战斗面板
                             │
                             ▼
                  更高难度内容 → 更多树脂产出效率
```

不消耗树脂的产出：野外采集（地方特产、素材）、宝箱（摩拉、经验书）、每日委托（摩拉、经验书、好感、原石）。这部分是**保底收益**，保证不氪不肝也能推进主线，但不足以支撑深度养成。

## 4. 属性来源汇总

一个 90 级满养成角色的面板由六个来源叠加而成。这张表是养成与战斗两个模块的接口定义：

| 来源 | 提供什么 | 写入哪个属性通道 |
| --- | --- | --- |
| 角色等级 | 基础生命、基础攻击、基础防御 | `Hp` / `Atk` / `Def` 的 **Base** 通道 |
| 角色突破 | 第二属性（暴击率、攻击力%、元素伤害加成…） | 对应属性位的 Percent 或 Additive 通道 |
| 固有天赋 | 被动效果，少数提供属性 | 视效果而定 |
| 武器基础攻击力 | 基础攻击力 | `Atk` 的 **Base** 通道（**与角色基攻相加**） |
| 武器副属性 | 一条第二属性 | 对应属性位 |
| 圣遗物 | 主词条 5 条 + 副词条最多 20 条 | 对应属性位 |

**武器基攻计入 `Atk` 的 Base 通道**，与角色基攻相加后一起吃攻击力%加成。这是原神数值设计的核心，决定了攻击力%词条的价值，详见 [Combat/05A 第 4.1 节](../Combat/05A_属性位清单.md)。

属性位的完整清单、聚合方式与求值顺序全部在 [Combat/05A](../Combat/05A_属性位清单.md)，本案组不重复定义，也不新增属性位。

## 5. 养成节奏

一个角色从获取到满养成的关键节点：

| 节点 | 解锁条件 | 意义 |
| --- | --- | --- |
| Lv20 突破 1 | 材料 + 摩拉 | 解锁**固有天赋 1** |
| Lv40 突破 2 | 材料 + 摩拉 | 第二属性开始生效；天赋可升至 4 级 |
| Lv50 突破 3 | 材料 + 摩拉 | — |
| Lv60 突破 4 | 材料 + 摩拉 | 解锁**固有天赋 2** |
| Lv70 突破 5 | 材料 + 摩拉 | — |
| Lv80 突破 6 | 材料 + 摩拉 | 天赋可升至 10 级 |
| Lv90 | 经验书 | 面板满，进入圣遗物长期优化阶段 |

【待复核】固有天赋的解锁阶段与天赋等级上限表见 [02 天赋与命之座](02_天赋与命之座.md) 第 3 节。

**突破是等级的闸门**：等级到达阶段上限后必须消耗材料突破才能继续升级。这让养成进度由材料获取速度（即树脂）决定，而不是由经验堆积决定——这是整个养成节奏的调节阀，不能简化成「经验到了自动升级」。

## 6. 模块边界

| 模块 | 职责 | 对应目录 |
| --- | --- | --- |
| 角色成长 | 等级、经验、突破阶段、突破属性 | `Character/Logic/Growth/CharaLevelLogic`（扩展） |
| 天赋成长 | 三天赋等级、固有天赋、命座对天赋的加成 | `Character/Logic/Talent/`（扩展） |
| 命之座 | 命座解锁状态与效果投影 | `Character/Logic/Growth/`（新增） |
| 武器 | 等级、突破、副属性、精炼、被动 | `Character/Logic/Growth/WeaponLogic`（重构） |
| 圣遗物 | 部位、词条、强化、套装 | `Character/Logic/Growth/EquipmentLogic`（重构） |
| 背包与材料 | 材料持有、消耗、合成 | `BagSystem`（扩展） |
| 树脂与秘境 | 树脂恢复与消耗、秘境挑战与掉落 | 新增 |
| 冒险等阶 | AR / WL、内容解锁、敌人等级 | 新增 |

全部养成产出最终都以**永久 Effect 投影**的形式写入角色属性，沿用现有 `RuntimePermanentEffectProjection` 模式——这是现有实现里最值得保留的设计，见 [90 差异台账](90_现有实现差异台账.md)。

## 7. 存档边界

养成数据属于账号级持久状态，不随世界切换重建（`ARCH-LIFE-003` 的 Session 段或更长）。需要持久化的最小集合：

```text
角色：characterId → { 等级, 累计经验, 突破阶段, 三天赋等级, 命座数, 好感等级, 好感经验 }
武器：weaponUid  → { 武器Id, 等级, 累计经验, 突破阶段, 精炼等级, 装备在哪个角色 }
圣遗物：artifactUid → { 套装Id, 部位, 星级, 等级, 主词条, 副词条列表, 装备在哪个角色 }
账号：{ 冒险等阶, 冒险经验, 世界等级, 摩拉, 原粹树脂, 树脂上次恢复时间, 材料背包 }
```

**树脂必须存绝对恢复时间戳而非剩余量**，与 POI 刷新同理（见 `PoiSystem/WorldDataManagementDesign.md` §9.3）：这样离线恢复不需要模拟。
