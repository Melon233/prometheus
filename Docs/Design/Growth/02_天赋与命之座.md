# 02 天赋与命之座

## 1. 设计目标

天赋是角色**强度的主轴**：它直接缩放技能倍率，且升级成本随等级陡增，因此「练哪个天赋」是每个角色的第一决策。命之座则是抽卡深度的兑现方式——它不参与日常养成，只由重复抽到同名角色驱动。两者都作用在技能上，但资源来源完全不同，必须分开建模。

## 2. 天赋分类

| 类别 | 数量 | 可升级 | 说明 |
| --- | --- | --- | --- |
| 主动天赋 | 3 | 是 | 普通攻击（含重击与下落）、元素战技、元素爆发 |
| 固有天赋 | 2 | 否 | 突破解锁的被动效果 |
| 额外固有天赋 | 1 | 否 | 非战斗被动（采集、烹饪、探索等） |

**可升级的只有 3 个主动天赋**。普通攻击、重击、下落攻击共享同一个天赋等级，不分开升级。

## 3. 天赋等级

### 3.1 等级范围

基础范围 `Lv1 ~ Lv10`。命之座可把其中两个天赋各再提升 3 级，因此实际上限为 `Lv15`，见 5.3。

### 3.2 突破对天赋等级的限制

天赋等级上限受角色突破阶段约束：

| 突破阶段 | 天赋等级上限 |
| --- | --- |
| 0 | 1 |
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 8 |
| 5 | 10 |
| 6 | 10 |
【待复核】

这条约束把天赋养成与角色突破绑在一起：想升天赋必须先突破，想突破必须攒材料，材料要花树脂。**去掉这条限制会让整个养成节奏塌掉**。

### 3.3 天赋等级的作用

天赋等级**不是一个统一系数**，而是每一级对应一组独立的技能倍率。一个天赋的每个伤害段落、每个持续时间、每个治疗量都在 1–15 级上各有一个值。

数据落点是战斗案组的 `TalentMultiplier` 表（见 [Combat/05A 第 7 节](../Combat/05A_属性位清单.md)）：一行 = 一个天赋的一个段落在 15 个等级上的取值。本案不重复定义该表。

> **这是与现有实现最大的分歧**。现有 `TalentLogic` 用 `(等级-1) × 成长系数` 算出一个统一缩放，乘到所有段落上。原神里同一天赋的不同段落成长斜率不同（例如 E 的伤害和它的持续时间完全不按同一比例走），统一系数无法表达。详见 [90 差异台账](90_现有实现差异台账.md)。

### 3.4 升级消耗

| 类别 | 说明 |
| --- | --- |
| 天赋书 | 三个品阶（教导 / 指引 / 哲学），**按星期开放**，每个地区三种 |
| 怪物掉落 | 三个品阶，与突破用的是同一批 |
| 周本材料 | Lv7 起需要，来自周常首领 |
| 摩拉 | 随等级陡增 |
| 智识之冕 | **仅 Lv9→10 需要**，极稀缺 |

天赋书按星期开放是刻意的节流：它让「今天能练什么」由日期决定，制造回访理由。复刻时保留这一机制，具体开放表见 [05 养成材料与资源](05_养成材料与资源.md)。

## 4. 固有天赋

| 天赋 | 解锁条件 | 性质 |
| --- | --- | --- |
| 固有天赋 1 | 突破 1（Lv20）【待复核】 | 战斗被动 |
| 固有天赋 2 | 突破 4（Lv60）【待复核】 | 战斗被动 |
| 额外固有天赋 | 角色获得时即有 | 非战斗被动 |

固有天赋不可升级、无等级、无消耗。效果由 `EffectDefinition` 承载，解锁时施加一个永久 Effect，沿用现有 `RuntimePermanentEffectProjection` 模式。

**额外固有天赋是非战斗被动**（减少采集消耗、烹饪概率、队伍移动速度、缩短小地图刷新等），它不进入战斗结算，实现时应挂在对应的探索或生产系统上，而不是塞进战斗管线。

## 5. 命之座

### 5.1 规则

- 每个角色 6 个命座座位，按 1→6 顺序解锁，不可跳解。
- 解锁材料是**该角色的命座石**，由重复抽到同名角色转化而来。
- 命座效果永久生效，无等级、不可重置。

### 5.2 命座效果的典型分布

| 座位 | 常见性质 |
| --- | --- |
| C1 | 机制性增强 |
| C2 | 机制性增强 |
| C3 | **某个主动天赋 +3 级** |
| C4 | 机制性增强 |
| C5 | **另一个主动天赋 +3 级** |
| C6 | 强力终极增强 |

C3 与 C5 分别提升 E 和 Q 中的一个（具体哪个因角色而异），普通攻击天赋通常不被命座提升。

### 5.3 命座对天赋等级的作用

```text
天赋实际等级 = 基础等级(1..10) + 命座加成(0 或 3)
```

- 命座加成**突破 Lv10 上限**，最高到 Lv15。
- 命座加成是**加算到等级**，而不是额外倍率：Lv10 + 3 就是去查 `TalentMultiplier` 表的 Lv13 那一列。
- 命座加成不受突破阶段限制（3.2 的表只约束基础等级）。

### 5.4 与抽卡的关系

命座石的唯一来源是重复获得同名角色。抽卡规则属于商业化模块，本案只定义接口：**获得一个已拥有的角色时，转化为 1 个该角色的命座石**；命座已满 6 时转化为其它资源。具体转化物与数量由商业化案确定。

## 6. 配表

### 6.1 `TalentBase`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `talentId` | string | 主键 |
| `characterId` | string | 所属角色 |
| `slot` | TalentSlot | `NormalAttack` / `Skill` / `Burst` / `Passive1` / `Passive2` / `PassiveUtility` |
| `nameKey` / `descKey` | string | 本地化 key |
| `maxLevel` | int | 主动天赋填 10，固有天赋填 1 |
| `unlockAscensionPhase` | int | 固有天赋的解锁突破阶段；主动天赋填 0 |
| `effectIds` | list,string | 关联的 `EffectDefinition` |

### 6.2 `TalentUpgradeCost`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `costGroupId` | string | 主键之一 |
| `level` | int | 主键之一，目标等级 2–10 |
| `mora` | int | 摩拉消耗 |
| `materialIds` | list,string | 材料 ID |
| `materialCounts` | list,int | 对应数量 |

### 6.3 `Constellation`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `characterId` | string | 主键之一 |
| `index` | int | 主键之一，1–6 |
| `nameKey` / `descKey` | string | 本地化 key |
| `talentLevelBonusSlot` | TalentSlot | C3/C5 提升哪个天赋；其余座位填 `None` |
| `talentLevelBonus` | int | 提升级数，通常 3；其余座位填 0 |
| `effectIds` | list,string | 机制性效果 |

天赋的**倍率数据不在本案的表里**，它在战斗案组的 `TalentMultiplier` 表。本案的 `TalentBase` 只描述天赋的身份与解锁条件，两张表通过 `talentId` 关联。

## 7. 与现有实现的差异

| 项 | 现状 | 目标 |
| --- | --- | --- |
| 天赋数量 | 4 个（普攻 / 特攻 / 技能 / 大招）各自独立升级 | 3 个主动天赋，普攻含重击与下落；另有 3 个固有天赋 |
| 等级效果 | 统一系数 `(等级-1) × 0.1` 乘到所有段落 | 逐级逐段落查 `TalentMultiplier` 表 |
| 等级上限 | 配置固定 10 | 基础 10，受突破阶段约束，命座可至 15 |
| 升级消耗 | **不存在** | 天赋书 + 怪物掉落 + 周本材料 + 摩拉 + 皇冠 |
| 固有天赋 | **不存在** | 突破解锁，Effect 承载 |
| 命之座 | **不存在** | 6 座，含天赋 +3 |

保留：四个技能 Component 各自持有 `TalentGrowthState` 的分层结构，以及唯一 `Growth.{EntityId}.Talent` 永久 Effect 的投影方式。要改的是**等级如何转成数值**，不是等级存在哪。

### 7.1 命座的承载方式（已定）

命座效果按承载方式分三类，只有第三类需要结构支持：

| 类别 | 承载 |
| --- | --- |
| 数值改写（天赋 +3 级、冷却 −X、持续 +X） | 对已有配置项加减；C3/C5 走第 5.3 节的等级加算 |
| 机制性增强（减防、附魔、队伍增益、命中时触发） | `Constellation.effectIds` → `EffectDefinition`，现有 EffectSystem 已能承载 |
| 结构改写（普攻多一段、E 多一次充能） | 段落表多一行；改动作流程的逐个作为对应 Logic 的可选能力，不做通用机制 |

天赋本身**不做成完全数据驱动的动作图**：段落数值进表、动作流程仍是 Logic。理由与四条落地决定见 [承压接缝台账 S-04](../../Arch/LoadBearingSeams.md)。

## 8. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| T-01 | 突破 0 的角色升天赋 | 上限为 1，无法升级 |
| T-02 | 突破 2 的角色升天赋 | 可升至 4 级 |
| T-03 | 天赋 Lv9→10 | 额外要求智识之冕 |
| T-04 | 星期不对时进天赋秘境 | 该天赋书不产出 |
| T-05 | 解锁 C3 | 对应天赋等级 +3，可超过 10 |
| T-06 | Lv10 天赋 + C3 | 实际等级 13，倍率取表中 Lv13 列 |
| T-07 | C3 加成与突破上限 | 命座加成不受突破阶段限制 |
| T-08 | 重复获得已拥有角色 | 转化为 1 个命座石 |
| T-09 | 命座已满 6 时再获得 | 转化为其它资源，不丢失 |
| T-10 | 突破 1 完成 | 固有天赋 1 的 Effect 生效 |
| T-11 | 同一天赋的两个段落 | 各自按表成长，斜率可不同 |
