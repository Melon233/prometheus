# 06 冒险等阶与世界等级

## 1. 设计目标

冒险等阶（AR）与世界等级（WL）是**内容闸门**，不是养成线。AR 控制「什么时候能玩到什么」，WL 控制「敌人多强、掉落多好」。两者分离的意义在于：AR 只增不减且由玩家行为驱动，WL 则可以在一定范围内由玩家主动调节，让被强度卡住的玩家有退路。

## 2. 冒险等阶（Adventure Rank）

### 2.1 规则

- 范围 `AR1 ~ AR60`。
- 经验来源：主线与支线任务、每日委托、秘境首通、解锁传送点与神像、开启宝箱、探索度奖励。
- **只增不减**，无消耗。
- AR 经验与角色经验是两套完全独立的资源，互不转换。

### 2.2 解锁节奏

| AR | 解锁内容 |
| --- | --- |
| 5 | 每日委托 |
| 12 | 队伍第 4 个位置 |
| 16 | 第一次世界等级提升（WL1） |
| 20 | 深境螺旋前段 |
| 25 | 世界等级 2 |
| 30 | 周常首领 |
| 35 | 世界等级 3 |
| 40 | 世界等级 4、5★ 圣遗物开始产出 |
| 45 | 世界等级 5 |
| 50 | 世界等级 6 |
| 55 | 世界等级 7 |
| 60 | 世界等级 8，AR 满级 |
【待复核】具体解锁项与 AR 阈值需逐条确认。

**AR 上限同时是角色等级的间接闸门**：秘境与 Boss 的推荐等级随 WL 上升，练度跟不上就打不动，因此 AR 推进速度天然限制了养成速度。

## 3. 世界等级（World Level）

### 3.1 规则

- 范围 `WL0 ~ WL8`。
- 达到对应 AR 时**自动提升**（见 2.2 表），提升时给予一次性奖励。
- **可主动降低**：每次降低后有冷却（24 小时）才能再次调整；恢复时同样有冷却【待复核】。
- WL 决定三件事：敌人等级、敌人属性倍率、掉落品阶与数量。

### 3.2 世界等级的作用

| 作用 | 说明 |
| --- | --- |
| 敌人等级 | 野外与秘境敌人的基准等级，直接进伤害公式的防御区（见 [Combat/05 第 4.5 节](../Combat/05_伤害结算公式.md)） |
| 敌人属性倍率 | 生命值与攻击力的额外倍率 |
| 掉落品阶 | 高 WL 才产出高品阶材料（如 5★ 圣遗物需 WL≥4【待复核】） |
| 掉落数量 | 同一内容在高 WL 下产出更多 |

### 3.3 允许降低世界等级的理由

这是一个容易被砍掉的设计，但它解决一个真实问题：**玩家的 AR 增长速度与练度增长速度不一致**。探索型玩家 AR 冲得快、角色没练起来，会被卡在打不动的世界里，而 AR 又不可逆。允许降 WL 给了这类玩家退路。

复刻时保留该机制，并保留冷却——冷却防止玩家「打 Boss 时降级、领奖时升级」地来回套利。

## 4. 与养成的耦合点

```text
AR ──决定──→ 可进入的内容（秘境、周本、深渊）
 │
 └──驱动──→ WL ──决定──→ 敌人等级与强度
                  │
                  └──决定──→ 掉落品阶与数量 ──→ 养成速度
                                                    │
                                                    ▼
                                              角色练度
                                                    │
                                    能否打得动当前 WL 的内容 ←┘
```

这是一个**正反馈回路**，唯一的负反馈是「WL 可降」。设计上必须保证：任一 WL 下，用该阶段能拿到的材料练出的角色，能打得动该阶段的内容。这条约束是数值验收的主要依据。

## 5. 配表

### 5.1 `AdventureRank`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `rank` | int | 主键，1–60 |
| `expToNext` | int | 升到下一阶所需冒险经验；60 级填 0 |
| `unlockWorldLevel` | int | 达到本阶时提升到的世界等级；不提升填 -1 |
| `unlockFeatureIds` | list,string | 本阶解锁的功能 ID |
| `rewardIds` | list,string | 升阶奖励 |

### 5.2 `WorldLevel`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `worldLevel` | int | 主键，0–8 |
| `enemyLevel` | int | 野外敌人基准等级 |
| `enemyHpMultiplier` | float | 敌人生命值倍率 |
| `enemyAtkMultiplier` | float | 敌人攻击力倍率 |
| `minAdventureRank` | int | 可维持该世界等级的最低 AR |
| `adjustCooldownHours` | int | 调整冷却小时数 |
| `upgradeRewardIds` | list,string | 首次达到时的一次性奖励 |

敌人等级与倍率进入 [Combat/05A 第 6 节](../Combat/05A_属性位清单.md) 的 `EnemyAttribute` 求值：最终敌人属性 = 曲线值(等级) × 类型倍率 × 世界等级倍率。

## 6. 与现有实现的差异

现有实现**完全没有 AR 与 WL**。敌人等级、掉落、内容解锁都不存在对应机制。需要新增：

| 模块 | 说明 |
| --- | --- |
| 冒险等阶 | 新增；账号级状态，随存档持久化 |
| 世界等级 | 新增；影响敌人生成与掉落查表 |
| 功能解锁 | 新增；按 `unlockFeatureIds` 控制入口可见性 |
| 敌人等级注入 | `EnemySpawnConfig` 与 `EnemyAiLogic` 需要接受世界等级参数 |

现有 `EnemySpawnConfig` 直接配置敌人属性，改造后应改为「配置敌人 Id + 由世界等级查表得出等级与倍率」。这与 [Combat/07 敌人与战斗AI](../Combat/07_敌人与战斗AI.md) 的 `EnemyAttribute` 表结构一致。

## 7. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| AR-01 | AR 升到 16 | 世界等级自动提升到 1，给予一次性奖励 |
| AR-02 | 主动降低世界等级 | 敌人等级与掉落同步下降，进入冷却 |
| AR-03 | 冷却期内再次调整 | 拒绝并提示剩余时间 |
| AR-04 | WL4 时刷圣遗物秘境 | 开始产出 5★ 圣遗物 |
| AR-05 | 同一 Boss 在 WL3 与 WL6 | 等级与掉落数量均不同 |
| AR-06 | AR 未达阈值时访问周本 | 入口不可见 |
| AR-07 | 角色经验道具 | 不增加冒险经验 |
| AR-08 | 完成每日委托 | 同时给冒险经验、摩拉、角色经验与好感 |
