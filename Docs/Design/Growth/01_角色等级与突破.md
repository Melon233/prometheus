# 01 角色等级与突破

## 1. 设计目标

等级提供**确定的、可预期的**基础属性成长；突破在这条平滑曲线上打入六个闸门，把节奏控制权从「攒经验」转移到「攒材料」。两者必须分开建模：等级是连续推进的数值，突破是离散的阶段状态，各自有独立的上限与消耗。

## 2. 等级

### 2.1 等级范围

`Lv1 ~ Lv90`。当前可达上限由突破阶段决定，见 3.2。

### 2.2 基础属性

角色在任意等级的基础生命、基础攻击、基础防御按**角色成长曲线**求出：

```text
基础属性(等级, 突破阶段) = 一级基础值 × 曲线系数(等级) + 突破固定加值(突破阶段)
```

- `一级基础值`：每个角色三项各一个，配在 `CharacterBase` 表。
- `曲线系数`：按角色的成长曲线类型查表，同类型角色共用一条曲线。
- `突破固定加值`：每次突破为三项基础属性提供一次性固定提升，**不随等级变化**。

这三项写入 `Hp` / `Atk` / `Def` 的 **Base** 通道（见 [Combat/05A 第 4.1 节](../Combat/05A_属性位清单.md)），因此会被攻击力%、生命值%等词条放大。

【待复核】曲线系数表需实机逐级校准，见 5.2。

### 2.3 经验

- 经验道具：**冒险家的经验 1000 / 流浪者的经验 5000 / 大英雄的经验 20000**【待复核】。
- 升级同时消耗**摩拉**，消耗量按目标等级递增。
- 经验溢出：升到当前上限后多余经验保留在角色身上，突破后继续生效。
- 经验道具使用时按「尽量少浪费」原则自动配比，但玩家可手动指定。

### 2.4 与现有实现的关键差异

现有 `CharaLevelLogic` 用一条 `AnimationCurve` 把**归一化累计经验**映射到等级，等级是经验的函数。原神是**逐级经验表**：每一级到下一级需要的经验独立配置，且升级消耗摩拉。曲线映射无法表达「某几级特别贵」，也无法表达摩拉消耗，必须换成表。详见 [90 差异台账](90_现有实现差异台账.md)。

## 3. 突破

### 3.1 突破阶段

六次突破，阶段编号 `0 ~ 6`：

| 突破阶段 | 达成条件 | 突破后等级上限 |
| --- | --- | --- |
| 0 | 初始 | 20 |
| 1 | Lv20 + 材料 | 40 |
| 2 | Lv40 + 材料 | 50 |
| 3 | Lv50 + 材料 | 60 |
| 4 | Lv60 + 材料 | 70 |
| 5 | Lv70 + 材料 | 80 |
| 6 | Lv80 + 材料 | 90 |
【实测】

**突破不提升等级**：Lv20 突破后仍是 Lv20，只是上限抬到 40。这一点常被简化实现搞错。

### 3.2 突破的四项作用

每次突破同时产生四种效果，缺一不可：

1. **抬高等级上限**（见 3.1）
2. **提供基础属性固定加值**（见 2.2）
3. **解锁固有天赋**：突破 1 解锁固有天赋 1，突破 4 解锁固有天赋 2【待复核】
4. **提供第二属性**：见 3.3

### 3.3 第二属性（突破属性）

每个角色有且仅有一条第二属性，类型固定，数值随突破阶段按档位提升：

| 突破阶段 | 第二属性档位 |
| --- | --- |
| 0 | 0 |
| 1 | 0 |
| 2 | 1 |
| 3 | 2 |
| 4 | 2 |
| 5 | 3 |
| 6 | 4 |
【待复核】档位序列需实机确认。

**第二属性从突破 2 才开始生效**——突破 1 不提供第二属性，这是容易配错的一点。

可选的第二属性类型（全部对应 [Combat/05A](../Combat/05A_属性位清单.md) 中已有的属性位，本案不新增）：

| 第二属性 | 对应属性位 |
| --- | --- |
| 暴击率 | `CritRate` |
| 暴击伤害 | `CritDamage` |
| 攻击力% | `Atk` 的 Percent 通道 |
| 生命值% | `Hp` 的 Percent 通道 |
| 防御力% | `Def` 的 Percent 通道 |
| 元素精通 | `ElementalMastery` |
| 元素充能效率 | `EnergyRecharge` |
| 元素伤害加成 | `{元素}DamageBonus` |
| 物理伤害加成 | `PhysicalDamageBonus` |
| 治疗加成 | `HealingBonus` |

### 3.4 突破消耗

一次突破消耗四类东西：

| 类别 | 说明 |
| --- | --- |
| 元素晶石 | 与角色元素对应，四个品阶（碎屑 / 断片 / 块 / 晶石），来自世界 Boss |
| 地方特产 | 与角色所属地区绑定，野外采集，**不消耗树脂** |
| 怪物掉落 | 三个品阶，野外击杀获得 |
| 摩拉 | 数量随阶段递增 |

具体数量表见 [05 养成材料与资源](05_养成材料与资源.md)。

**地方特产不消耗树脂**是刻意设计：它让「探索」成为养成的必要环节，而不只是可选内容。复刻时不要把它改成树脂产出。

## 4. 状态机

```text
                 经验足够且未达阶段上限
Lv(n) ──────────────────────────────────→ Lv(n+1)
  │
  │ 等级 = 当前阶段上限
  ▼
等待突破 ──(材料 + 摩拉足够)──→ 突破确认 ──→ 阶段+1
  │                                            │
  │ 材料不足                                   ├─ 等级上限抬高
  └──── 阻塞，经验继续累积但不升级 ←───────────┤─ 基础属性固定加值
                                               ├─ 第二属性档位提升
                                               └─ 可能解锁固有天赋
```

**等待突破期间经验继续累积**，突破后一次性结算，不浪费。

## 5. 配表

表结构与类型写法遵循 [Docs/Workflow/ConfigPipeline.md](../../Workflow/ConfigPipeline.md)。

**三张表已建好并跑通导表**，位于 `Data/Excel/Datas/Growth/`：

| 表 | 数据文件 | mode | 行数 |
| --- | --- | --- | --- |
| `TbCharacterBase` | `character_base.xlsx` | map | 1（占位） |
| `TbCharacterLevelCurve` | `character_level_curve.xlsx` | list | 90（占位曲线） |
| `TbCharacterAscension` | `character_ascension.xlsx` | list | 6 |

> **当前数值为占位，禁止据此做平衡判断。** 已确认的只有结构：突破六阶段的等级序列与第二属性档位序列。其余字段标 `#confidence = Placeholder`，需实机反解后替换。
>
> `CharacterLevelCurve` 与 `CharacterAscension` 天然需要两个主键（`curveId + level`、`characterId + phase`），而 **Luban 不支持复合主键**，因此采用 `mode = list` 不声明 `index`，保持「一行一级」的行布局，查询索引由消费方在初始化时构建一次。详见 [ConfigPipeline 第 3.4 节](../../Workflow/ConfigPipeline.md)。

### 5.1 `CharacterBase`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `characterId` | string | 主键 |
| `nameKey` | string | 角色名本地化 key |
| `rarity` | int | 星级，4 或 5 |
| `element` | ElementType | 角色元素 |
| `weaponType` | WeaponType | 单手剑 / 双手剑 / 长柄 / 弓 / 法器 |
| `regionId` | string | 所属地区，决定突破用地方特产 |
| `baseHp` / `baseAtk` / `baseDef` | float | 一级基础值 |
| `growthCurveId` | string | 成长曲线 ID |
| `ascensionSecondaryAttr` | string | 第二属性对应的属性位 ID |
| `ascensionMaterialGroupId` | string | 突破材料组 ID |

### 5.2 `CharacterLevelCurve`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `curveId` | string | 主键之一，曲线 ID |
| `level` | int | 主键之一，1–90 |
| `coefficient` | float | 该等级的基础属性系数 |
| `expToNext` | int | 升到下一级需要的经验；90 级填 0 |
| `moraToNext` | int | 升到下一级需要的摩拉；90 级填 0 |

**必须实机填表，禁止用公式近似**。这张表同时决定了三项基础属性和全程经验/摩拉消耗，是养成节奏的主干。

### 5.3 `CharacterAscension`

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `characterId` | string | 主键之一 |
| `phase` | int | 主键之一，1–6 |
| `requiredLevel` | int | 突破所需等级 |
| `unlockLevelCap` | int | 突破后等级上限 |
| `addHp` / `addAtk` / `addDef` | float | 三项基础属性固定加值 |
| `secondaryAttrTier` | int | 第二属性档位 |
| `unlockPassiveTalentId` | string | 本阶段解锁的固有天赋；无则留空 |
| `mora` | int | 摩拉消耗 |
| `materialIds` | list,string | 材料 ID 列表 |
| `materialCounts` | list,int | 对应数量，与上一列等长 |

## 6. 实现状态

等级与突破的**数据层与状态机已落地**，由 `CharaLevelComponent` / `CharaLevelLogic` 承载：

| 项 | 状态 |
| --- | --- |
| 逐级表驱动等级（累加 `expToNext`） | 已完成 |
| 六阶段突破状态机、等级上限闸门 | 已完成 |
| 等待突破期间经验积压、突破后继续升级 | 已完成 |
| 三项基础属性增量（`baseXxx × (系数-1) + Σ突破加值`） | 已完成 |
| 第二属性按档位生效（突破 2 起） | 已完成，覆盖 3.3 的全部类型 |
| 三项基础属性写入 Base 通道 | 已完成 |
| 固有天赋解锁事件 | 已发出（`PassiveTalentUnlocked`），消费方待 02 落地 |
| 突破消耗以 `MaterialCost` 表达 | 已完成，校验走 `IBagSystem.CheckCost` |
| 材料实际扣减 | **未完成**，属服务器权威，见 [05 第 7.1 节](05_养成材料与资源.md) |

先前的两处偏离已随 [Combat/05A](../Combat/05A_属性位清单.md) 的属性位落地而收敛：

1. **属性通道**已改为 `Base`。三项基础属性与配置基础值相加后一起被攻击力%这类词条放大，符合本案 2.2。
2. **第二属性覆盖面**已补全，覆盖 3.3 节列出的全部类型。未知标识现在直接抛出而非静默跳过——标识来自配表，拼错不应当表现为「属性莫名其妙没生效」。

仍未收敛的一项：一级基础值有两个来源——`TbCharacterBase.baseXxx`（用于算增量）与 `PropertyConfig`（提供 1 级基底）。两者必须保持一致，统一到表尚未做。

## 7. 与现有实现的差异

| 项 | 现状 | 目标 |
| --- | --- | --- |
| 等级来源 | `AnimationCurve` 映射归一化经验 | 逐级经验表 `CharacterLevelCurve` |
| 突破 | **不存在** | 六阶段状态机，见 3 |
| 基础属性 | 只有攻击力，线性 `最高攻击 / (上限-1) × (等级-1)` | 三项属性各按曲线 + 突破加值 |
| 第二属性 | **不存在** | 按突破档位提供 |
| 固有天赋 | **不存在** | 突破 1 / 4 解锁 |
| 摩拉消耗 | **不存在** | 升级与突破均消耗 |

现有的**永久 Effect 投影**（`Growth.{EntityId}.CharaLevel`）与**运行时副本隔离**两项设计保留，新增内容沿用同样模式。

## 8. 验收用例

| 编号 | 用例 | 期望 |
| --- | --- | --- |
| G-01 | Lv1 角色喂满经验 | 停在 Lv20，经验溢出保留 |
| G-02 | Lv20 执行突破 | 等级仍为 20，上限变 40 |
| G-03 | 突破 1 完成 | 解锁固有天赋 1，第二属性仍为 0 |
| G-04 | 突破 2 完成 | 第二属性开始生效，档位为 1 |
| G-05 | 材料不足时突破 | 拒绝并提示缺口，不扣除任何资源 |
| G-06 | 突破后基础属性 | 三项均按 `CharacterAscension` 的加值提升 |
| G-07 | 攻击力% 词条与突破加值 | 突破加值计入 Base 通道，被百分比放大 |
| G-08 | 等待突破期间继续喂经验 | 经验累积，等级不变，突破后不丢失 |
| G-09 | 同一角色的三个实例 | 养成数据互相独立 |
| G-10 | Lv90 满级 | 无法继续投入经验，提示已满级 |
