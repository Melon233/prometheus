# Blender 风格化岩石插件（Stylized Rock）

> 适用范围：在 Blender 中把关卡白盒非破坏性地转换成原神风格的岩石，可随时挂载、卸载并实时调参
> 代码位置：`Tools/Blender/addons/stylized_rock/`（`__init__.py` 负责挂载、面板和更新；`generator.py` 负责几何算法）
> 要求：Blender 4.2 及以上（用到 numpy 与 BVHTree），本机实测 Blender 5.0.1
> 首次编写时间：2026-10-14

---

## 1. 安装（每台机器一次）

1. Blender → 编辑 → 偏好设置 → 文件路径 → **脚本目录**，新增一项，路径填仓库内的 `Tools/Blender`。
2. 偏好设置 → 插件，刷新后搜索 **Stylized Rock** 并勾选启用。
3. 保存偏好设置。

插件直接从仓库目录加载，`git pull` 之后在插件列表里关闭再打开（或重启 Blender）即可用上新代码。

## 2. 使用

| 操作 | 方法 |
|---|---|
| 挂载 | 选中白盒，在 属性编辑器 → 物体 → **风格化岩石** 面板（或 3D 视图 N 侧栏 → **岩石** 标签）勾选"挂载岩石"；生成后白盒自动隐藏（线框显示、不参与渲染） |
| 调参 | 直接拖动面板参数，岩石**立即重新生成**（每块约 10–40 ms） |
| 卸载 | 取消勾选"挂载岩石"：删除岩石物体及网格，白盒重新显示、恢复实体显示并重新参与渲染 |
| 编辑白盒形状 | 选中岩石，点"显示/隐藏白盒"叫出白盒，编辑完点"重新生成"（作用于选中的白盒或岩石）；"全部重新生成"作用于场景内所有已挂载白盒 |
| 移动白盒 | 不用重算：岩石是白盒的子物体，会直接跟随 |
| 批量改参数 | 选中多个白盒，在参数上右键 → "复制到选定项"，每个白盒都会触发重算 |

选中岩石时，面板显示的是它所属白盒的参数，可以直接在岩石上调参。

## 3. 参数

设计目标是参考原神中的单块岩体：**整体连续、只有顶部长草、侧面靠大切面和节理概括**。"切面尺寸"和"倒角宽度"为 0 时按白盒尺寸自动推算。

| 分组 | 参数 | 默认 | 说明 |
|---|---|---|---|
| — | 种子 / 材质 | 0 / 空 | 换种子就是另一块石头；材质留空则不赋材质 |
| 体量 | 融合度 | 0.5 | 白盒的台阶、侧挑块被抹平成连续岩体的程度。0 = 紧贴白盒，1 = 沿高度方向强平滑（高斯 σ ≈ 0.2×总高）。想保留顶帽、悬挑等外凸，调到 0.1–0.3 |
| 体量 | 顶部起伏 | 0 | 顶部轮廓高低错落的幅度（米）。0 = 平顶；调大后顶部变成参差的岩峰 |
| 切面 | 切面尺寸 | 自动 | 大切面的平均尺寸（米），决定粗网格疏密。自动值 `max(1, √(平均周长×高)/9)` |
| 切面 | 切面起伏 | 0.1 | 每个顶点随机向内收的最大比例，越大切面朝向越杂、折线越深 |
| 切面 | 平切强度 | 0.6 | 局部平切的刀数（约为 强度×顶点数/3），越大跨多个三角面的大平面越多 |
| 切面 | 平切倾斜 | 0.3 | 刀面相对局部表面的随机倾斜，越大平切面越偏离原表面 |
| 节理 | 竖向节理 | 3 | 竖向 V 形裂缝条数 |
| 节理 | 节理深度 | 0.15 | 裂缝处向内收的比例 |
| 节理 | 横向层理 | 0.4 | 按环整体内收的幅度，越大水平层理缝越明显 |
| 质感 | 圆度 | 0.2 | 0 = 硬朗悬崖（窄倒角、WeightedNormal 保持切面平整）；大于 0.5 加 2 级细分，磨圆成石块 |
| 质感 | 倒角宽度 | 自动 | 棱边倒角宽度（米），自动值 `切面尺寸×(0.04+0.12×圆度)` |
| 顶部遮罩 | 顶部起始 / 完全 | 0.75 / 0.9 | 只对顶部盖面生效：盖面法线 Z 在两值之间平滑过渡到 1 |

参考图左侧那种棱角分明、顶部参差的悬崖，可以从这组参数起步：融合度 0.2、切面起伏 0.22、平切强度 1.2、平切倾斜 0.5、竖向节理 4、节理深度 0.25、横向层理 0.6、顶部起伏 1.2。

## 4. 数据关系与生成链路

```
白盒.stylized_rock（参数组）──result──▶ 岩石物体（集合 StylizedRocks，父物体 = 白盒）
岩石.stylized_rock_source ───────────▶ 白盒
```

- **参数变化 → `on_param` → `regenerate`**：调用 `generator.build(白盒, 参数)` 得到白盒局部坐标的网格和修改器配置。已有岩石只替换网格（旧网格无人使用时删除），没有就新建。新网格的 `TopMask` 设为活动和渲染顶点色。
- **挂载开关 → `on_enabled`**：打开时先生成岩石，再把白盒隐藏（`hide_set`）、改为线框、不参与渲染；关闭时卸载并重新显示白盒。白盒隐藏后，选中岩石即可在面板里调它的参数。
- **复制白盒**（Shift+D）：副本的参数里 `result` 仍指向原件的岩石，但那块岩石的 `stylized_rock_source` 不是副本，所以副本首次重算时会新建自己的岩石，不会抢走原件的。
- **岩石上的修改器由插件全权管理**：每次重算都会清空后重建（Bevel → Subsurf 或 WeightedNormal）。手动加在岩石上的修改器会丢失。

### 几何算法（`generator.py`）

把白盒当作**一整块岩体的体量参考**，不再逐块拉伸：

1. **外包络**（`Envelope`）：在白盒高度范围内每 0.25 米取一层，从中轴外侧沿 96 个方位角水平朝中轴打射线，记录最外侧表面到中轴的距离 r(θ, z)。射线长度限制在中轴外侧，同一高度的多个重叠块自然取最外层。
   - 中轴取各高度截面的面积形心，并沿高度平滑，允许岩体倾斜。共采样两遍：第一遍以包围盒中心为轴求形心，第二遍用平滑后的形心重采样。中心偏到截面外时，第一遍会有方向打不到，第二遍会修正。
2. **融合**：r 沿高度做高斯平滑（σ 由融合度决定），沿方位角固定轻微平滑，去掉白盒棱角的锯齿。
3. **粗网格**（`Grid`）：每环 M 个顶点（M = 平均周长 / 切面尺寸，取 8–48），侧墙 R 环（R ≈ 高 / 切面尺寸，取 2–24）。自下而上依次是：
   - 地下环：统一埋深，向内收，作平底；
   - 接地环：高度随机起伏；
   - R−1 个侧墙环：整环高度抖动 ±30% 环距；横向层理让整环统一内收；
   - 倒角带底环；
   - 顶环：内收 8%–18% 形成切面状的顶边，高度随顶部起伏下沉。
   顶点方位角在列中心 ±30% 列宽内随机错位，半径取包络值再随机内收（切面起伏）。
4. **局部平切**：随机挑选侧墙顶点作为刀位，刀面取该处的局部切平面（相邻顶点差分）加随机倾斜，并略向内推。半径 切面尺寸×(0.9–1.6) 内的顶点沿径向截到刀面上：只削不补，最多削掉 45%。多个三角面被截到同一平面上，就形成了大平切面。
5. **竖向节理**：随机若干列，在一段连续的环上整列内收，形成竖向 V 形裂缝。
6. **去尖刺**：每个侧墙顶点的径向距离不超过上下左右四个邻点平均值的 1.12 倍，消除平切和节理漏掉的孤立尖角。
7. **建网格**：相邻两环之间的四边形随机选对角线拆成两个三角形；底部和顶部用扇形封口。顶部盖面中心的高度随顶部起伏变化。
8. **写顶部遮罩**：**只有顶部盖面**按面法线 Z 做 smoothstep，写入面角域字节颜色属性 `TopMask` 的 R 通道（G/B = 0，A = 1）。侧墙、外凸、层理缝一律为 0。
9. 转换到白盒局部坐标。

**不自交的保证**：所有顶点只在"本环中心沿方位角 θ 的水平射线"上移动，各环高度严格递增，同一环内方位角顺序不变。所以每个高度的截面都是关于中心的星形多边形，生成的网格不会自交。

相同种子、相同参数的输出是确定的。

## 5. 导出到 Unity

- 顶部遮罩在顶点色 `TopMask` 的 **R 通道**（0 = 岩石，1 = 顶部草或苔藓）。FBX 导出时勾选顶点色（Vertex Colors），Unity 着色器里读 `COLOR.r` 混合岩石和草的纹理。
- Blender 里的预览材质 `M_StylizedRock` 已改为读 `TopMask`：顶点色的 R 通道加一点噪声后，经过原来的阈值映射混合草色，和 Unity 端用的是同一份数据。注意：材质最初由场景内的 `style.py` 生成，重新运行该脚本会把这处改动覆盖回"按法线判断"。

## 6. 白盒建模约定与限制

- **一个白盒 = 一块岩体**。每个高度的白盒截面应大致关于中轴呈星形；同一高度上分开的两块（两根柱子、拱门）无法表达，需要拆成两个白盒。
- 白盒可以由多个互相重叠的封闭块拼成，生成时只取最外层轮廓，内部的重叠不影响结果。
- 台阶、顶帽、侧挑这类体量会按融合度被抹成连续的收分和外凸，**白盒里的平台不会保留为可以站人的平台**。外凸部分的下方自然形成往里收的斜面。
- 白盒移动后岩石跟随，但白盒的世界高度变化**不会**改变岩石形状（形状只在重算时按当时的世界坐标计算）。白盒只应绕 Z 轴旋转。
