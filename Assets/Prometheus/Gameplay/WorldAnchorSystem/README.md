# WorldAnchorSystem（世界锚点）

## 目标

给场景中的「世界内容」——NPC、地标、广场中心等不管有没有任务都存在的东西——一个稳定的 id，供演出与任务按 id 引用。
锚点属于关卡：同一个 NPC 只挂一个 `WorldAnchor`，任意多个任务与演出都可以引用它。任务专属的区域与交互点写在任务资产里、运行时生成，场景中不摆放任务专属组件。

## 用法

1. 在 NPC 根节点、地标或空物体上添加 `WorldAnchor`，填写场景内唯一的 `anchorId`（例如 `npc_barbarossa`、`anchor_square`）。场景视图中锚点显示为橙色小球和 id 标签。
2. 演出资产的 `anchorId`（坐标原点）与 Scene 来源演员的 `anchorId`、任务资产的区域锚点与交互挂载锚点都填这个 id。
3. 编辑期用菜单 `Prometheus/Narrative/校验场景锚点` 核对：全部演出与任务引用的 id 是否都在当前打开的场景里，以及有没有无人引用的锚点。

## 运行链路

- 组合根在演出与任务之前注册本系统（两者通过构造注入 `IWorldAnchorSystem`）。
- `AfterNew`：扫描场景中全部 `WorldAnchor`（含未激活对象），按 id 建立索引；id 为空或重复直接抛出。
- `Require(id, owner)`：取锚点 Transform；不存在时抛出，错误信息带上引用方（哪个演出/任务节点）。
- `Dispose`：只清空索引，锚点是场景对象，不归本系统所有。

游戏是单世界设计，场景在会话建立前已加载，因此只在会话建立时扫描一次；将来引入世界切换时需要随场景重建索引。
