# World shaders

Project-owned Lit world shaders belong here. They should include `Assets/Prometheus/Rendering/ShaderLibrary/PrometheusEnvironment.hlsl` and explicitly decide how daily light, ambient light, seasonal tint, fog, depth, and shadows affect each material family.

`Prometheus/Rendering/World/Grid Lit` draws an anti-aliased triplanar grid without depending on mesh UVs. Cell size, line width, and offset use physical world units in an object-oriented coordinate frame, so the grid follows object translation and rotation while avoiding non-uniform scale distortion. Base color, line color, metallic, smoothness, triplanar projection sharpness, and seasonal tint strength are material properties. The shader participates in URP PBR lighting, main and additional lights, realtime shadows, baked GI, fog, and the Prometheus season shader-global contract. Main-light shadow coordinates use URP Lit's conditional path: vertex interpolation is reserved for compatible variants, while cascaded main-light shadows are transformed per pixel to avoid interpolating coordinates from different cascade matrices across sparse triangles.

Grid Lit 的 `UniversalForward` 与 `UniversalGBuffer` Pass 都必须通过 `ProbeVolumeVariants.hlsl` 编译 `PROBE_VOLUMES_L1` 和 `PROBE_VOLUMES_L2` 变体，确保 `Receive Global Illumination = Light Probes` 的网格能够由 `SAMPLE_GI` 读取 Adaptive Probe Volumes。顶点阶段使用 `OUTPUT_SH4` 输出 APV 顶点数据和可选遮蔽，像素阶段按 URP 17 的 APV 签名传入绝对世界坐标、法线、视线、屏幕坐标和遮蔽数据；Lightmap、旧式球谐与屏幕空间 Irradiance 继续走各自独立分支。新增或重构 Lit Pass 时不得只保留 `LIGHTMAP_ON` 变体，否则该 Pass 会退回非 APV 的球谐路径，已经生成的 Probe Volume 数据也不会参与表面照明。
