# 资源规格契约模板（TA 用）

> 使用方式：策划案过「策划评审门」后，TA 从各 feature 的「美术需求」字段抽取，汇总成此契约。经「契约确认门」人工批准后，作为美术组与开发组的硬约束下发。

---

## 契约基本信息

| 字段 | 内容 |
|---|---|
| 契约 ID | 例：`SPEC-v0.1-001` |
| 关联 Feature | CMB-001, CMB-010, … |
| 版本范围 | v0.1 |
| 批准人 | PM / 主策划 |
| 状态 | 草稿 / 已批准 / 变更中 |

---

## 一、命名规则

> （美术产出与开发引用必须一致，否则集成阶段无法换资源）

| 资源类型 | 命名格式 | 示例 |
|---|---|---|
| 模型 | `M_系统_名称_序号` | `M_Player_Hero_01` |
| 动画 | `A_角色_动作_序号` | `A_Hero_Attack_03` |
| 特效 | `VFX_系统_名称` | `VFX_Hit_Normal` |
| 贴图 | `T_用途_名称_后缀` | `T_Albedo_Hero_01` |
| 音效 | `SFX_系统_动作_序号` | `SFX_Combat_Attack_03` |
| UI | `UI_系统_控件` | `UI_Combat_ComboHint` |

---

## 二、目录结构

```
Assets/
├── Art/
│   ├── Models/      # 模型
│   ├── Animations/  # 动画
│   ├── VFX/         # 特效
│   ├── Audio/       # 音效
│   └── UI/          # UI
├── Data/            # 数值配置（策划调表处）
└── Prefabs/         # 预制体
```

---

## 三、格式与规格

| 项目 | 规范 |
|---|---|
| 模型格式 | FBX，三角面 / 顶点上限见性能预算表 |
| 贴图格式 | PNG（透明通道）/ TGA，尺寸须为 2 的幂 |
| 贴图最大尺寸 | 1024×1024（主角）/ 512×512（通用） |
| 动画格式 | 骨骼动画，人形角色用 Humanoid |
| 音效格式 | WAV 44.1kHz / OGG |
| 坐标系 | 右手系，Y 轴向上 |

---

## 四、性能预算表（单帧 / 单场景）

| 资源项 | 预算上限 | 说明 |
|---|---|---|
| 三角面总数 | 300k | 场景所有可见模型 |
| 单个角色面数 | 15k | 主角 |
| 特效粒子峰值 | 200 / 特效 | 同屏特效粒子总数 ≤1000 |
| 贴图显存 | 256 MB | 全场景 |
| 骨骼数量 | ≤64 / 角色 | |
| Draw Call | ≤150 | |

---

## 五、接口契约（给开发组）

> （资源 ID 与事件名，开发只认这些，不认具体文件）

| 接口 | 定义 | 关联 Feature |
|---|---|---|
| 资源 ID | `M_Player_Hero_01` | CMB-001 |
| 动画状态 | `Attack_1 / Attack_2 / Attack_3` | CMB-001 |
| 事件 | `OnHitVFX(id)` / `OnHitSFX(id)` | CMB-010 |
| 占位资源路径 | `Art/Placeholder/Hero_Box` | 开发先行 |

---

## 六、变更控制

- 契约任何变更必须走「变更评审」，回写 Feature Spec。
- 禁止开发 / 美术私下改契约；发现冲突报 TA 仲裁。
