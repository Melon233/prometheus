# 工作流流程图

> 以下流程图为 Mermaid 语法，可在支持 Mermaid 的 Markdown 工具（Typora / Obsidian / VS Code 插件 / GitLab）中直接渲染。

---

## 一、端到端总流程图

```mermaid
flowchart TD
    A["阶段0 立项<br/>主策划输出立项案<br/>PM 定里程碑"] --> G0{"G0 立项门"}
    G0 -- 驳回 --> A
    G0 -- 通过 --> B["阶段1 策划细化<br/>战斗系统策划案初稿"]

    B --> C["策划组 AI<br/>Web检索 + 自主评审 + lint"]
    C --> G1{"G1 策划评审门<br/>人工润色裁决"}
    G1 -- 驳回 --> B
    G1 -- 通过 --> D["阶段2 需求拆解<br/>feature → ticket + 依赖图"]

    D --> E["TA 契约抽取<br/>接口契约 + 资源规格契约"]
    E --> G2{"G2 契约确认门"}
    G2 -- 驳回 --> D
    G2 -- 通过 --> F["阶段3 三线并行<br/>开发 / 美术 / TA"]

    F --> H["阶段4 集成<br/>换资源 + 性能检查"]
    H --> G3{"G3 集成门"}
    G3 -- 驳回 --> F
    G3 -- 通过 --> I["阶段5 测试<br/>AC 生成用例 + 三层测试"]

    I --> G4{"G4 测试门"}
    G4 -- "有 bug（缺陷回环）" --> F
    G4 -- 通过 --> J["阶段6 验收与复盘<br/>对照里程碑 + 沉淀回流"]

    J -. "复盘意见回流" .-> B
```

## 二、阶段 1 策划细化（G1 门）详细图

```mermaid
flowchart TD
    A["主策划输出<br/>战斗系统策划案初稿"] --> B["策划组 AI 预审"]
    B --> B1["Web 检索<br/>竞品机制 / 行业标准"]
    B --> B2["自主评审<br/>一致性 / 完整性 / 歧义 / 依赖"]
    B --> B3["自动 lint<br/>模糊词黑名单扫描"]
    B1 --> C["汇总《评审报告》"]
    B2 --> C
    B3 --> C
    C --> D{"人工润色裁决"}
    D -- 驳回 --> A
    D -- 通过 --> E["输出跨角色可读的<br/>Feature Spec"]
```

## 三、阶段 3 三线并行详细图

```mermaid
flowchart TD
    SRC["策划案定稿（契约源）"] --> TA["TA 组：契约抽取"]

    TA --> IC["接口契约<br/>数据/函数签名/资源ID/占位路径"]
    TA --> RC["资源规格契约<br/>命名/目录/格式/性能预算"]

    IC --> DEV["开发组<br/>占位资源 + 接口契约 开发逻辑"]
    RC --> ART["美术组<br/>按规格契约 产出正式资源"]

    DEV --> INT["集成：换资源"]
    ART --> CHECK{"TA 规范校验门"}
    CHECK -- 驳回（给清单） --> ART
    CHECK -- 通过 --> INT

    INT --> G3{"G3 集成门"}
    G3 -- 驳回 --> TA
    G3 -- 通过 --> OUT["流入测试"]
```

## 四、缺陷回环图（G4 门）

```mermaid
flowchart LR
    T["测试发现 bug"] --> B["挂接 Feature ID"]
    B --> R{"定位责任组"}
    R -- 开发 --> D["开发修复"]
    R -- 美术 --> A["美术修复"]
    R -- TA --> TA2["TA 调整契约/管线"]
    D --> V["复测"]
    A --> V
    TA2 --> V
    V --> P{"AC 通过？"}
    P -- 否 --> B
    P -- 是 --> C["关闭 bug，回流沉淀"]
```

## 五、六节点协作关系图

```mermaid
flowchart LR
    PM[PM<br/>范围/里程碑/验收] --> DESIGN[策划组<br/>Feature Spec]
    DESIGN --> TA[TA组<br/>契约/规范/管线]
    TA --> ART[美术组<br/>资源生产]
    TA --> DEV[开发组<br/>逻辑实现]
    ART --> QA[测试组<br/>AC 用例/三层测试]
    DEV --> QA
    QA --> PM
    DESIGN -. "契约源" .-> TA
```
